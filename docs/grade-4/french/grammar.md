!!! info "Objectifs du chapitre"

    - Identifier les classes de mots (nom, verbe, adjectif, determinant, pronom, adverbe)
    - Reconnaitre les fonctions dans la phrase (sujet, COD, COI, complements circonstanciels)
    - Analyser une phrase simple et complexe

## Les classes de mots

### Dans la vraie vie : pourquoi connaitre les classes de mots ?

!!! tip "Ca t'aide partout !"

    **Pour l'orthographe :**

    - Si tu sais qu'un mot est un verbe, tu peux le conjuguer correctement
    - Si tu sais qu'un mot est un adjectif, tu peux l'accorder avec le nom

    **Pour la redaction :**

    - Tu peux enrichir tes phrases avec des adjectifs et des adverbes
    - Tu evites les repetitions en utilisant des pronoms

---

## Le nom

Le **nom** designe une personne, un animal, une chose ou une idee.

!!! note "Types de noms"
    - **Nom commun** : chat, table, courage (minuscule)
    - **Nom propre** : Paris, Marie, Everest (majuscule)

!!! example "Exemples"
    - Le **chien** joue dans le **jardin**. (noms communs)
    - **Lucas** habite a **Lyon**. (noms propres)

---

## Le determinant

Le **determinant** accompagne toujours le nom. Il indique le genre (masculin/feminin) et le nombre (singulier/pluriel).

| Type | Exemples |
|------|----------|
| Articles definis | le, la, l', les |
| Articles indefinis | un, une, des |
| Determinants possessifs | mon, ton, son, ma, ta, sa, mes, tes, ses, notre, votre, leur... |
| Determinants demonstratifs | ce, cet, cette, ces |

!!! example "Exemples"
    - **Le** chat mange **sa** croquette.
    - **Cette** maison est **la** mienne.

---

## L'adjectif qualificatif

L'**adjectif qualificatif** donne une precision sur le nom. Il s'accorde en genre et en nombre avec le nom.

!!! example "Exemples"
    - Un **grand** arbre → Une **grande** maison
    - Des fleurs **rouges** → Un ballon **rouge**

??? warning "Piege a eviter : la place de l'adjectif"
    La plupart des adjectifs se placent **apres** le nom :

    - Un chat **noir** (pas "un noir chat")
    - Une voiture **rapide**

    Mais certains adjectifs courants se placent **avant** :

    - Un **petit** chat, une **grande** maison, un **beau** jardin

---

## Le verbe

Le **verbe** exprime une action ou un etat. C'est le mot qui se conjugue.

!!! note "Comment le reconnaitre ?"
    - Il change selon le temps : je **mange**, je **mangeais**, je **mangerai**
    - Il change selon la personne : je **mange**, tu **manges**, il **mange**

!!! example "Exemples"
    - Le chat **dort** sur le canape. (action)
    - Marie **est** contente. (etat)

---

## Le pronom

Le **pronom** remplace un nom pour eviter les repetitions.

| Type | Exemples |
|------|----------|
| Pronoms personnels sujets | je, tu, il, elle, on, nous, vous, ils, elles |
| Pronoms personnels complements | me, te, le, la, lui, nous, vous, les, leur |
| Pronoms possessifs | le mien, le tien, le sien... |
| Pronoms demonstratifs | celui, celle, ceux, celles, celui-ci... |

!!! example "Exemple"
    - Marie mange une pomme. → **Elle** **la** mange.
    - J'ai vu les enfants. Je **leur** ai parle.

---

## L'adverbe

L'**adverbe** modifie le sens d'un verbe, d'un adjectif ou d'un autre adverbe. Il est **invariable**.

!!! example "Exemples"
    - Il court **vite**. (modifie le verbe)
    - Elle est **tres** gentille. (modifie l'adjectif)
    - Il parle **trop** fort. (modifie l'adverbe)

!!! tip "Astuce"
    Beaucoup d'adverbes se terminent en **-ment** : lentement, rapidement, gentiment...

---

## Les fonctions dans la phrase

### Le sujet

Le **sujet** indique qui fait l'action ou de qui/quoi on parle.

!!! note "Comment le trouver ?"
    Pose la question : **"Qui est-ce qui...?"** ou **"Qu'est-ce qui...?"** + verbe

!!! example "Exemples"
    - **Le chat** dort. (Qui est-ce qui dort ? → Le chat)
    - **Mes amis et moi** jouons. (Qui est-ce qui joue ? → Mes amis et moi)

---

### Le COD (Complement d'Objet Direct)

Le **COD** complete le verbe directement, sans preposition.

!!! note "Comment le trouver ?"
    Pose la question : sujet + verbe + **"qui ?"** ou **"quoi ?"**

!!! example "Exemples"
    - Je mange **une pomme**. (Je mange quoi ? → une pomme = COD)
    - Il regarde **son frere**. (Il regarde qui ? → son frere = COD)

---

### Le COI (Complement d'Objet Indirect)

Le **COI** complete le verbe avec une preposition (a, de, pour...).

!!! note "Comment le trouver ?"
    Pose la question : sujet + verbe + **"a qui ?"**, **"de quoi ?"**...

!!! example "Exemples"
    - Je parle **a ma mere**. (Je parle a qui ? → a ma mere = COI)
    - Il pense **a ses vacances**. (Il pense a quoi ? → a ses vacances = COI)

---

### Les complements circonstanciels

Les **complements circonstanciels** (CC) indiquent les circonstances de l'action. Ils sont souvent deplacables et supprimables.

| Type | Question | Exemple |
|------|----------|---------|
| CC de lieu | Ou ? | Il joue **dans le jardin**. |
| CC de temps | Quand ? | Il viendra **demain**. |
| CC de maniere | Comment ? | Elle chante **doucement**. |
| CC de cause | Pourquoi ? | Il pleure **de joie**. |

---

## Resume : tableau des classes et fonctions

| Classe de mot | Role | Exemple |
|---------------|------|---------|
| Nom | Designe | chat, Paris |
| Determinant | Accompagne le nom | le, une, mon |
| Adjectif | Qualifie le nom | grand, rouge |
| Verbe | Action/etat | manger, etre |
| Pronom | Remplace le nom | il, elle, le |
| Adverbe | Modifie (invariable) | vite, bien |

| Fonction | Role | Exemple |
|----------|------|---------|
| Sujet | Fait l'action | **Le chat** mange. |
| COD | Complete directement | Il mange **la souris**. |
| COI | Complete avec preposition | Il pense **a toi**. |
| CC | Circonstances | Il dort **dans son lit**. |

## Exercices

### Exercice 1 : Classes de mots

!!! question "Trouve la classe de chaque mot souligne"
    1. Le **petit** chat dort.
    2. Elle **mange** une pomme.
    3. **Nous** partons demain.

??? success "Correction"
    1. petit = **adjectif qualificatif**
    2. mange = **verbe**
    3. Nous = **pronom personnel**

### Exercice 2 : Fonctions

!!! question "Trouve la fonction des groupes soulignes"
    1. **Marie** mange une glace.
    2. Je regarde **un film**.
    3. Il parle **a son ami**.

??? success "Correction"
    1. Marie = **sujet**
    2. un film = **COD**
    3. a son ami = **COI**
