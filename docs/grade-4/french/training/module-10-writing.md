## Ecrire un recit

### La structure

Un recit doit suivre le **schema narratif** :

1. **Situation initiale** : presente les personnages, le lieu, le moment
2. **Element perturbateur** : un evenement change tout
3. **Peripeties** : les actions, les aventures
4. **Resolution** : le probleme est resolu
5. **Situation finale** : comment ca se termine

### Les temps du recit

!!! note "Quels temps utiliser ?"
    - **Imparfait** : descriptions, actions qui durent
    - **Passe simple** : actions ponctuelles (a l'ecrit)
    - **Passe compose** : actions ponctuelles (a l'oral/ecrit courant)

!!! example "Exemple"
    "Il **faisait** beau ce jour-la. (imparfait = description)
    Soudain, un loup **apparut**. (passe simple = action ponctuelle)
    Le garcon **cria** et **s'enfuit**." (passe simple = actions)

### Les connecteurs temporels

| Pour commencer | Pour enchainer | Pour finir |
|----------------|----------------|------------|
| Il etait une fois | Puis, ensuite | Enfin |
| Un jour | Alors | Finalement |
| Ce matin-la | Soudain | A la fin |
| | Tout a coup | |

## Ecrire un dialogue

### Les regles de presentation

!!! note "Comment presenter un dialogue"
    - **Guillemets** pour ouvrir et fermer
    - **Tiret** a chaque changement de personnage
    - **Verbes de parole** : dit, demanda, repondit, s'exclama...
    - **Ponctuation** avant de fermer les guillemets

### Exemple

```
Marie entra dans la cuisine et demanda :
« Maman, ou est mon sac ?
- Il est dans ta chambre, repondit sa mere.
- Merci ! » s'exclama Marie.
```

### Les verbes de parole

| Neutres | Emotions | Questions |
|---------|----------|-----------|
| dire | s'ecrier | demander |
| repondre | murmurer | questionner |
| ajouter | crier | interroger |
| reprendre | chuchoter | s'enquierir |
| declarer | soupirer | |

## Ecrire une description

### Organiser sa description

!!! tip "L'ordre de la description"
    - **Vue d'ensemble** → **details**
    - **Du plus proche** → **au plus loin** (ou inverse)
    - **Du haut** → **vers le bas**
    - **De gauche** → **a droite**

### Enrichir sa description

| Element | Comment l'enrichir |
|---------|-------------------|
| Noms | Ajouter des **adjectifs** |
| Verbes | Ajouter des **adverbes** |
| Phrases | Ajouter des **complements** |

!!! example "Exemple"
    - **Basique** : La maison est grande.
    - **Enrichi** : L'**imposante** maison **aux volets bleus** se dresse **fierement** au sommet de la colline.

### Le vocabulaire des 5 sens

| Sens | Vocabulaire |
|------|-------------|
| **Vue** | couleurs, formes, tailles, lumiere |
| **Ouie** | bruit, silence, cri, murmure |
| **Odorat** | parfum, odeur, senteur |
| **Toucher** | doux, rugueux, lisse, froid |
| **Gout** | sucre, sale, amer, acide |

## Ameliorer ses ecrits

### La relecture

!!! note "Checklist de relecture"
    - [ ] La ponctuation est correcte
    - [ ] Les phrases ont un sens
    - [ ] Les accords sont faits (sujet-verbe, GN)
    - [ ] Les homophones sont corrects
    - [ ] Le texte est bien organise

### Eviter les repetitions

!!! tip "Solutions"
    - Utiliser des **synonymes**
    - Utiliser des **pronoms**
    - Varier les **structures de phrases**

!!! example "Exemple"
    - **Avec repetitions** : Le chat mange. Le chat dort. Le chat joue.
    - **Sans repetitions** : Le chat mange. **Il** dort ensuite **puis** joue.

### Enrichir son vocabulaire

| Au lieu de... | Utilise... |
|---------------|------------|
| dit | declara, affirma, murmura |
| beau | magnifique, splendide, superbe |
| grand | immense, enorme, gigantesque |
| petit | minuscule, minime, infime |

## Exercices guides

### Exercice 1 : Suite de recit

!!! question "Continue ce debut"
    "Il etait une fois un jeune garcon qui vivait dans un village au pied d'une montagne. Un matin, il decouvrit une carte au tresor dans le grenier de sa maison..."

??? success "Exemple de suite"
    Le garcon, tout excite, decida de partir a l'aventure. Il prepara un sac avec du pain et de l'eau, puis s'elanca vers la montagne.

    Apres plusieurs heures de marche, il arriva devant une grotte sombre. Son coeur battait fort. Il entra prudemment...

### Exercice 2 : Dialogue

!!! question "Ecris un dialogue entre deux amis"
    Sujet : ils preparent une fete surprise.

??? success "Exemple"
    Lucas retrouva son ami dans la cour et chuchota :
    « Tu as prevu les ballons pour la fete de Marie ?
    - Oui, j'en ai achete vingt ! repondit Thomas. Et toi, le gateau ?
    - Ma mere le prepare ce soir. Il sera au chocolat, son prefere !
    - Genial ! Elle va etre tellement surprise ! » s'exclama Thomas.
