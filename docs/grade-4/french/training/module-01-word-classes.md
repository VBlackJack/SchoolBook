# Module 1 - Les classes de mots

!!! abstract "Objectifs"
    A la fin de ce module, tu sauras :

    - Identifier les 6 classes de mots principales
    - Reconnaitre un nom, un determinant, un adjectif
    - Reconnaitre un verbe, un pronom, un adverbe
    - Classer les mots d'une phrase

    **Duree estimee** : 2 heures

---

## Introduction

Chaque mot de la langue francaise appartient a une **classe grammaticale** (ou "nature"). Connaitre la classe d'un mot, c'est comme connaitre son "metier" dans la phrase !

!!! tip "Pourquoi c'est important ?"
    - Pour faire les **accords** correctement
    - Pour **analyser** une phrase
    - Pour **enrichir** tes ecrits

---

## Les 6 classes principales

### 1. Le nom

Le **nom** designe une personne, un animal, une chose ou une idee.

| Type | Exemples |
|------|----------|
| Nom commun | chat, table, courage, joie |
| Nom propre | Paris, Marie, France |

!!! note "Comment le reconnaitre ?"
    - On peut mettre **un/une/des** devant : **un** chat, **une** table
    - Il a un **genre** (masculin/feminin) et un **nombre** (singulier/pluriel)

---

### 2. Le determinant

Le **determinant** accompagne le nom et indique son genre et son nombre.

| Type | Exemples |
|------|----------|
| Articles | le, la, l', les, un, une, des |
| Possessifs | mon, ton, son, ma, ta, sa, mes, tes, ses... |
| Demonstratifs | ce, cet, cette, ces |
| Indefinis | chaque, quelques, plusieurs, aucun... |

!!! note "Comment le reconnaitre ?"
    - Il est toujours **devant un nom**
    - On peut le remplacer par un autre determinant

---

### 3. L'adjectif qualificatif

L'**adjectif** donne une information sur le nom. Il s'accorde avec lui.

!!! example "Exemples"
    - un **grand** arbre (comment est l'arbre ?)
    - une fleur **rouge** (comment est la fleur ?)
    - des enfants **joyeux** (comment sont les enfants ?)

!!! note "Comment le reconnaitre ?"
    - Il donne une **qualite** ou une **caracteristique**
    - On peut le supprimer (la phrase reste correcte)
    - Il s'**accorde** avec le nom

---

### 4. Le verbe

Le **verbe** exprime une action ou un etat. C'est le mot qui se **conjugue**.

!!! example "Exemples"
    - Le chat **mange**. (action)
    - Elle **est** contente. (etat)
    - Nous **avons** faim. (etat)

!!! note "Comment le reconnaitre ?"
    - Il **change** selon la personne : je mange, tu manges, il mange
    - Il **change** selon le temps : je mange, je mangeais, je mangerai

---

### 5. Le pronom

Le **pronom** remplace un nom (ou un groupe nominal) pour eviter les repetitions.

| Type | Exemples |
|------|----------|
| Personnels sujets | je, tu, il, elle, on, nous, vous, ils, elles |
| Personnels complements | me, te, le, la, lui, nous, vous, les, leur |
| Possessifs | le mien, la tienne, les notres... |
| Demonstratifs | celui, celle, ceux, celles, celui-ci... |

!!! example "Exemple"
    - Marie mange une pomme. → **Elle** **la** mange.
    - Je parle a Pierre. → Je **lui** parle.

---

### 6. L'adverbe

L'**adverbe** modifie le sens d'un verbe, d'un adjectif ou d'un autre adverbe. Il est **invariable** (ne s'accorde jamais).

!!! example "Exemples"
    - Il court **vite**. (modifie le verbe)
    - Elle est **tres** gentille. (modifie l'adjectif)
    - Il parle **trop** fort. (modifie l'adverbe)

!!! tip "Astuce"
    Beaucoup d'adverbes finissent en **-ment** : lentement, rapidement, gentiment, doucement...

---

## Resume

| Classe | Role | Variable ? | Exemples |
|--------|------|:----------:|----------|
| **Nom** | Designe | Oui | chat, Paris, joie |
| **Determinant** | Accompagne le nom | Oui | le, une, mon, ces |
| **Adjectif** | Qualifie le nom | Oui | grand, rouge, joyeux |
| **Verbe** | Action ou etat | Oui (conjugue) | manger, etre, avoir |
| **Pronom** | Remplace le nom | Oui | il, elle, le, lui |
| **Adverbe** | Modifie | **Non** | vite, bien, tres |

## Exercices guides

### Exercice 1

!!! question "Trouve la classe de chaque mot"
    Phrase : "Le petit chat mange rapidement."

??? success "Correction"
    - Le = **determinant** (article defini)
    - petit = **adjectif** (qualifie "chat")
    - chat = **nom** (commun)
    - mange = **verbe** (action)
    - rapidement = **adverbe** (modifie "mange", invariable)

### Exercice 2

!!! question "Trouve la classe de chaque mot"
    Phrase : "Elle lui donne son cadeau."

??? success "Correction"
    - Elle = **pronom** (personnel sujet)
    - lui = **pronom** (personnel complement)
    - donne = **verbe** (action)
    - son = **determinant** (possessif)
    - cadeau = **nom** (commun)

## Entrainement

### Serie 1 : Facile

!!! note "Trouve la classe de chaque mot souligne"
    1. **Une** fille joue.
    2. Le chat **noir** dort.
    3. Il **court** vite.
    4. **Nous** partons demain.

??? success "Corrections"
    1. Une = **determinant**
    2. noir = **adjectif**
    3. court = **verbe**
    4. Nous = **pronom**

### Serie 2 : Moyen

!!! note "Identifie toutes les classes de mots"
    "Mon ami joue bien."

??? success "Correction"
    - Mon = **determinant** (possessif)
    - ami = **nom** (commun)
    - joue = **verbe**
    - bien = **adverbe**

### Serie 3 : Difficile

!!! note "Identifie toutes les classes de mots"
    "Cette grande maison blanche appartient a mes grands-parents."

??? success "Correction"
    - Cette = **determinant** (demonstratif)
    - grande = **adjectif**
    - maison = **nom**
    - blanche = **adjectif**
    - appartient = **verbe**
    - a = **preposition** (mot invariable - bonus !)
    - mes = **determinant** (possessif)
    - grands-parents = **nom** (compose)

## Bilan

!!! summary "Ce que tu dois retenir"
    - **Nom** : designe (personne, animal, chose, idee)
    - **Determinant** : accompagne le nom (le, une, mon...)
    - **Adjectif** : qualifie le nom (grand, rouge...)
    - **Verbe** : action ou etat, se conjugue
    - **Pronom** : remplace le nom (il, elle, lui...)
    - **Adverbe** : modifie, **invariable** (vite, bien, tres...)
