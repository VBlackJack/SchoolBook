# Module 5 - Orthographe grammaticale

!!! abstract "Objectifs"
    A la fin de ce module, tu sauras :

    - Faire les accords dans le groupe nominal
    - Faire l'accord sujet-verbe
    - Distinguer les homophones grammaticaux

    **Duree estimee** : 2 heures

---

## L'accord dans le groupe nominal

### Regle

!!! note "Regle d'or"
    Dans le groupe nominal, le **determinant** et l'**adjectif** s'accordent avec le **nom** en genre et en nombre.

### Exemples

| Singulier | Pluriel |
|-----------|---------|
| **un** chat **noir** | **des** chat**s** **noir**s |
| **une** fleur **rouge** | **des** fleur**s** **rouge**s |
| **le** **grand** jardin | **les** **grand**s jardin**s** |

### Cas particuliers

??? warning "Les adjectifs de couleur"
    **Simples** → s'accordent : bleu**s**, rouge**s**, vert**es**

    **Issus de noms** → invariables : orange, marron, turquoise

    - des robes **bleues**
    - des robes **orange** (comme le fruit)

## L'accord sujet-verbe

### Regle

!!! note "Regle d'or"
    Le verbe s'accorde avec le **sujet** en personne et en nombre.

### Comment trouver le sujet ?

Pose la question : **"Qui est-ce qui + verbe ?"**

### Exemples

!!! example "Exemples"
    - **Le chat** mange. (il = 3e pers. sing.)
    - **Les enfants** jouent. (ils = 3e pers. plur.)
    - **Marie et moi** partons. (nous = 1re pers. plur.)

### Pieges

??? warning "Pieges a eviter"
    **Piege 1 : Sujet eloigne**

    - Les oiseaux, sur la branche, **chantent**. (pas "chante")

    **Piege 2 : Sujet inverse**

    - Dans le jardin **jouent** les enfants.

    **Piege 3 : Sujet collectif**

    - La foule **applaudit**. (singulier)
    - Beaucoup de gens **applaudissent**. (pluriel)

## Les homophones grammaticaux

### a / a

| a (sans accent) | a (avec accent) |
|-----------------|-----------------|
| Verbe AVOIR | Preposition |
| → remplacable par **avait** | → pas remplacable |

!!! example "Exemples"
    - Il **a** faim. → Il **avait** faim.
    - Je vais **a** Paris. → Je vais ~~avait~~ Paris.

### et / est

| et | est |
|----|-----|
| Conjonction | Verbe ETRE |
| → remplacable par **et puis** | → remplacable par **etait** |

!!! example "Exemples"
    - Marie **et** Lucie jouent. → Marie **et puis** Lucie.
    - Il **est** content. → Il **etait** content.

### son / sont

| son | sont |
|-----|------|
| Determinant possessif | Verbe ETRE |
| → remplacable par **mon** | → remplacable par **etaient** |

!!! example "Exemples"
    - **Son** chien est gentil. → **Mon** chien.
    - Ils **sont** partis. → Ils **etaient** partis.

### on / ont

| on | ont |
|----|-----|
| Pronom (= quelqu'un) | Verbe AVOIR |
| → remplacable par **il** | → remplacable par **avaient** |

!!! example "Exemples"
    - **On** joue au foot. → **Il** joue.
    - Ils **ont** faim. → Ils **avaient** faim.

### ou / ou

| ou (sans accent) | ou (avec accent) |
|------------------|------------------|
| Conjonction (choix) | Adverbe de lieu |
| → remplacable par **ou bien** | → remplacable par **la-bas** |

### ce / se

| ce | se |
|----|-----|
| Determinant demonstratif | Pronom reflexif |
| → devant un **nom** | → devant un **verbe** |

!!! example "Exemples"
    - **Ce** livre est bien. (ce + nom)
    - Il **se** leve tot. (se + verbe)

### ces / ses / c'est / s'est

| ces | ses | c'est | s'est |
|-----|-----|-------|-------|
| Demonstratif pluriel | Possessif pluriel | ce + est | se + est |
| → ces...la | → son/sa au singulier | → cela est | → il s'est (pronominal) |

---

## Resume des homophones

| Homophones | Astuce |
|------------|--------|
| a / a | a = avait |
| et / est | est = etait |
| son / sont | son = mon |
| on / ont | ont = avaient |
| ou / ou | ou = ou bien |
| ce / se | ce + nom / se + verbe |

## Exercices guides

### Exercice 1

!!! question "Complete avec a ou a"
    1. Elle ... mange une pomme.
    2. Je vais ... l'ecole.
    3. Mon ami ... dix ans.

??? success "Correction"
    1. Elle **a** mange (avait).
    2. Je vais **a** l'ecole (preposition).
    3. Mon ami **a** dix ans (avait).

### Exercice 2

!!! question "Accorde les adjectifs"
    1. des fleurs (rouge)
    2. une (grand) maison
    3. les (petit) chats (noir)

??? success "Correction"
    1. des fleurs **rouges**
    2. une **grande** maison
    3. les **petits** chats **noirs**

## Entrainement

### Serie 1 : Homophones

!!! note "Complete avec le bon homophone"
    1. Elle ... partie avec ... frere. (a/a, son/sont)
    2. ... va au cinema ... au theatre ? (on/ont, ou/ou)
    3. ... enfants ... contents. (ce/se, ces/ses, son/sont)

??? success "Corrections"
    1. Elle **est** partie avec **son** frere.
    2. **On** va au cinema **ou** au theatre ?
    3. **Ces** enfants **sont** contents.

### Serie 2 : Accords

!!! note "Corrige les erreurs"
    1. Les petit chat noir joue.
    2. Elle a manger une pomme.
    3. Les fille sont parti.

??? success "Corrections"
    1. Les **petits** chat**s** **noirs** **jouent**.
    2. Elle a **mange** une pomme.
    3. Les **filles** sont **parties**.

## Evaluation

!!! warning "A faire sans aide"

**Q1-Q6.** Complete avec le bon homophone :

1. Il ... un chien. (a/a)
2. Marie ... Pierre jouent. (et/est)
3. ... partez demain. (on/ont)
4. ... vas-tu ? (ou/ou)
5. ... livre est bien. (ce/se)
6. Ils ... fini. (son/sont)

**Q7-Q10.** Accorde correctement :

7. des maisons (blanc)
8. les (grand) arbres (vert)
9. Les oiseaux (chanter) dans le jardin.
10. Marie et Lucie (etre) contentes.

??? success "Corrections"
    1. Il **a** un chien.
    2. Marie **et** Pierre jouent.
    3. **On** partez demain.
    4. **Ou** vas-tu ?
    5. **Ce** livre est bien.
    6. Ils **ont** fini.
    7. des maisons **blanches**
    8. les **grands** arbres **verts**
    9. Les oiseaux **chantent** dans le jardin.
    10. Marie et Lucie **sont** contentes.

## Bilan

!!! summary "Ce que tu dois retenir"
    - **Groupe nominal** : tout s'accorde avec le nom
    - **Sujet-verbe** : le verbe s'accorde avec le sujet
    - **Homophones** : utilise les astuces de remplacement
