# Module 7 - Vocabulaire

!!! abstract "Objectifs"
    A la fin de ce module, tu sauras :

    - Trouver des synonymes et des antonymes
    - Identifier les mots d'une meme famille
    - Comprendre les prefixes et suffixes
    - Utiliser le dictionnaire efficacement

    **Duree estimee** : 1h30

---

## Les synonymes

Les **synonymes** sont des mots qui ont **le meme sens** ou un sens tres proche.

!!! example "Exemples"
    - content = **heureux**, joyeux, satisfait, ravi
    - beau = **joli**, magnifique, splendide
    - manger = **se nourrir**, devorer, grignoter
    - maison = **habitation**, demeure, logement

!!! tip "Pourquoi utiliser des synonymes ?"
    - Pour **eviter les repetitions**
    - Pour **enrichir** ton vocabulaire
    - Pour **nuancer** ton propos

### Attention aux nuances

!!! warning "Les synonymes ne sont pas toujours interchangeables"
    - "manger" est neutre
    - "devorer" = manger avec appetit
    - "grignoter" = manger peu, par petits morceaux

---

## Les antonymes

Les **antonymes** sont des mots de **sens contraire**.

!!! example "Exemples"
    - grand ≠ **petit**
    - chaud ≠ **froid**
    - monter ≠ **descendre**
    - commencer ≠ **finir**, terminer
    - aimer ≠ **detester**
    - beau ≠ **laid**

### Formation des antonymes avec prefixes

Certains prefixes permettent de former des antonymes :

| Prefixe | Sens | Exemples |
|---------|------|----------|
| **in-/im-** | contraire | possible → **im**possible |
| **de-/des-** | contraire | faire → **de**faire |
| **mal-** | mal | heureux → **mal**heureux |

---

## Les familles de mots

Une **famille de mots** regroupe tous les mots formes a partir d'un meme **radical** (racine).

!!! example "Famille du mot TERRE"
    - **terre** (radical)
    - **terr**ain
    - **terr**asse
    - en**terr**er
    - de**terr**er
    - **terr**estre
    - a**terr**ir

!!! example "Famille du mot CHANT"
    - **chant** (radical)
    - **chant**er
    - **chant**eur
    - **chant**euse
    - en**chant**er
    - en**chant**ement

!!! tip "A quoi ca sert ?"
    - Trouver l'orthographe d'un mot (lettres muettes)
    - Comprendre le sens d'un mot nouveau
    - Enrichir ton vocabulaire

---

## Les prefixes

Le **prefixe** se place **avant** le radical et modifie le sens du mot.

| Prefixe | Sens | Exemples |
|---------|------|----------|
| **re-** | de nouveau | faire → **re**faire |
| **de-/des-** | contraire | monter → **de**monter |
| **in-/im-** | contraire | utile → **in**utile |
| **pre-** | avant | voir → **pre**voir |
| **para-** | contre | pluie → **para**pluie |
| **anti-** | contre | vol → **anti**vol |

---

## Les suffixes

Le **suffixe** se place **apres** le radical et peut changer la classe du mot.

| Suffixe | Classe formee | Exemples |
|---------|---------------|----------|
| **-eur/-euse** | nom (metier) | chanter → chant**eur** |
| **-tion/-sion** | nom (action) | punir → puni**tion** |
| **-ment** | adverbe | lent → lente**ment** |
| **-able/-ible** | adjectif | manger → mange**able** |
| **-ette/-et** | diminutif | maison → maisonn**ette** |

---

## Utiliser le dictionnaire

### Les informations du dictionnaire

!!! note "Ce qu'on trouve dans le dictionnaire"
    1. **L'orthographe** du mot
    2. **La classe grammaticale** (n., v., adj...)
    3. **Le genre** pour les noms (m. ou f.)
    4. **La definition** (sens du mot)
    5. **Des exemples** d'utilisation
    6. **Les synonymes** et antonymes

### L'ordre alphabetique

!!! tip "Rappel"
    Pour trouver un mot, utilise l'ordre alphabetique.

    Si les premieres lettres sont identiques, compare les lettres suivantes :

    - **ba**teau est avant **be**au (a avant e)
    - **cha**t est avant **che**val (a avant e)

## Entrainement

### Serie 1 : Synonymes et antonymes

!!! note "Trouve un synonyme et un antonyme"
    1. joyeux
    2. facile
    3. monter

??? success "Corrections"
    1. joyeux : syn. = **content**, heureux / ant. = **triste**
    2. facile : syn. = **simple**, aise / ant. = **difficile**
    3. monter : syn. = **grimper**, escalader / ant. = **descendre**

### Serie 2 : Familles de mots

!!! note "Trouve le radical commun"
    1. danser, danseur, danse
    2. lent, lentement, lenteur, ralentir
    3. porter, portable, transport, reporter

??? success "Corrections"
    1. **dans-**
    2. **lent-**
    3. **port-**

### Serie 3 : Prefixes et suffixes

!!! note "Decompose le mot"
    1. impossible
    2. refaire
    3. chanteur
    4. lentement

??? success "Corrections"
    1. **im-** (prefixe) + possible
    2. **re-** (prefixe) + faire
    3. chant + **-eur** (suffixe)
    4. lente + **-ment** (suffixe)

## Bilan

!!! summary "Ce que tu dois retenir"
    - **Synonymes** : meme sens (content = heureux)
    - **Antonymes** : sens contraire (grand ≠ petit)
    - **Famille de mots** : meme radical (terre, terrain, terrasse)
    - **Prefixe** : avant le radical, change le sens
    - **Suffixe** : apres le radical, change souvent la classe
