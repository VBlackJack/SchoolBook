# Module 8 - La phrase

!!! abstract "Objectifs"
    A la fin de ce module, tu sauras :

    - Identifier les 4 types de phrases
    - Reconnaitre les formes de phrases
    - Utiliser correctement la ponctuation
    - Construire des phrases complexes

    **Duree estimee** : 1h30

---

## Les 4 types de phrases

### 1. La phrase declarative

Elle **declare** quelque chose, donne une information.

!!! example "Exemples"
    - Le chat dort sur le canape**.**
    - J'aime le chocolat**.**

**Ponctuation** : point (.)

---

### 2. La phrase interrogative

Elle pose une **question**.

!!! example "Exemples"
    - Est-ce que tu viens **?**
    - Ou vas-tu **?**
    - Tu viens **?**

**Ponctuation** : point d'interrogation (?)

### Les 3 facons de poser une question

| Facon | Exemple | Niveau de langue |
|-------|---------|------------------|
| Intonation | Tu viens ? | Familier |
| Est-ce que | Est-ce que tu viens ? | Courant |
| Inversion | Viens-tu ? | Soutenu |

---

### 3. La phrase exclamative

Elle exprime une **emotion** forte (joie, colere, surprise...).

!!! example "Exemples"
    - Quel beau paysage **!**
    - Comme c'est joli **!**
    - J'ai gagne **!**

**Ponctuation** : point d'exclamation (!)

---

### 4. La phrase imperative (injonctive)

Elle donne un **ordre**, un **conseil** ou une **interdiction**.

!!! example "Exemples"
    - Viens ici **!** (ordre)
    - N'oublie pas ton sac **.** (conseil)
    - Sortez immediatement **!** (ordre)

**Ponctuation** : point ou point d'exclamation

!!! note "Caracteristique"
    Le verbe est a l'**imperatif** (pas de sujet exprime).

---

## Les formes de phrases

Chaque type de phrase peut etre **affirmative** ou **negative**.

### Phrase affirmative

Elle dit "oui" a quelque chose.

!!! example "Exemple"
    - Je mange une pomme.
    - Tu viens demain.

### Phrase negative

Elle dit "non" a quelque chose.

!!! note "Structure"
    **ne ... pas** / **ne ... plus** / **ne ... jamais** / **ne ... rien**

!!! example "Exemples"
    - Je **ne** mange **pas** de pomme.
    - Il **ne** vient **plus**.
    - Elle **ne** dit **jamais** bonjour.
    - Tu **ne** fais **rien**.

??? warning "Piege a eviter"
    A l'oral, on oublie souvent le "ne". A l'ecrit, il est **obligatoire** !

    - Oral : "Je veux pas." ✗
    - Ecrit : "Je **ne** veux **pas**." ✓

## La ponctuation

| Signe | Nom | Usage |
|:-----:|-----|-------|
| **.** | Point | Fin de phrase declarative |
| **?** | Point d'interrogation | Fin de question |
| **!** | Point d'exclamation | Emotion, ordre |
| **,** | Virgule | Pause, enumeration |
| **;** | Point-virgule | Pause moyenne |
| **:** | Deux-points | Explication, enumeration |
| **...** | Points de suspension | Phrase inachevee |
| **"** **"** | Guillemets | Paroles, citations |
| **-** | Tiret | Dialogue |

### La virgule

!!! tip "Quand mettre une virgule ?"
    - **Enumeration** : J'aime les pommes**,** les poires**,** les cerises et les fraises.
    - **Apposition** : Marie**,** ma soeur**,** est partie.
    - **CC en debut de phrase** : Hier**,** je suis alle au cinema.

---

## La phrase simple et la phrase complexe

### Phrase simple

Elle contient **un seul verbe conjugue**.

!!! example "Exemple"
    - Le chat **dort**. (1 verbe)

### Phrase complexe

Elle contient **plusieurs verbes conjugues**.

!!! example "Exemple"
    - Le chat **dort** et le chien **joue**. (2 verbes)
    - Je **pense** qu'il **viendra**. (2 verbes)

## Exercices guides

### Exercice 1

!!! question "Identifie le type de phrase"
    1. Ou vas-tu ?
    2. Le soleil brille.
    3. Viens ici !
    4. Comme c'est beau !

??? success "Correction"
    1. **Interrogative** (question)
    2. **Declarative** (information)
    3. **Imperative** (ordre)
    4. **Exclamative** (emotion)

### Exercice 2

!!! question "Transforme a la forme negative"
    1. Je mange du chocolat.
    2. Il vient toujours.
    3. Elle dit quelque chose.

??? success "Correction"
    1. Je **ne** mange **pas** de chocolat.
    2. Il **ne** vient **jamais**.
    3. Elle **ne** dit **rien**.

## Entrainement

### Serie 1 : Types de phrases

!!! note "Identifie le type"
    1. Est-ce que tu as fini ?
    2. Quelle belle journee !
    3. Fermez la porte.
    4. Le train arrive a midi.

??? success "Corrections"
    1. **Interrogative**
    2. **Exclamative**
    3. **Imperative**
    4. **Declarative**

### Serie 2 : Formes de phrases

!!! note "Transforme a la forme negative"
    1. J'ai tout compris.
    2. Il mange encore.
    3. Quelqu'un est venu.

??? success "Corrections"
    1. Je **n'**ai **rien** compris.
    2. Il **ne** mange **plus**.
    3. **Personne n'**est venu.

### Serie 3 : Ponctuation

!!! note "Ajoute la ponctuation"
    1. Ou est mon sac
    2. Je suis content
    3. Viens ici tout de suite
    4. Quel magnifique coucher de soleil

??? success "Corrections"
    1. Ou est mon sac **?**
    2. Je suis content **.**
    3. Viens ici tout de suite **!**
    4. Quel magnifique coucher de soleil **!**

    2. **Declarative**
    3. **Exclamative**

    7. **Personne n'**a telephone.
    8. Je **n'**ai **jamais** faim.

## Bilan

!!! summary "Ce que tu dois retenir"
    - **4 types** : declarative (.), interrogative (?), exclamative (!), imperative
    - **2 formes** : affirmative et negative (ne...pas/plus/jamais/rien)
    - **Ponctuation** : chaque signe a son usage
    - **Phrase simple** : 1 verbe / **Phrase complexe** : plusieurs verbes
