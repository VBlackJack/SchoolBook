# Module 2 - Les fonctions dans la phrase

!!! abstract "Objectifs"
    A la fin de ce module, tu sauras :

    - Trouver le sujet d'un verbe
    - Identifier le COD (Complement d'Objet Direct)
    - Identifier le COI (Complement d'Objet Indirect)
    - Reconnaitre les complements circonstanciels

    **Duree estimee** : 2 heures

---

## Introduction

La **classe** d'un mot, c'est sa nature (nom, verbe, adjectif...).
La **fonction** d'un mot, c'est son role dans la phrase.

!!! tip "Analogie"
    - **Classe** = ce que tu ES (eleve, professeur, directeur)
    - **Fonction** = ce que tu FAIS dans l'ecole (apprendre, enseigner, diriger)

    Un **nom** peut avoir la fonction de sujet, COD, COI...

---

## Le sujet

Le **sujet** indique **qui fait l'action** ou **de qui/quoi on parle**.

### Comment le trouver ?

!!! note "Methode"
    Pose la question : **"Qui est-ce qui + verbe ?"** ou **"Qu'est-ce qui + verbe ?"**

!!! example "Exemples"
    - **Le chat** dort. → Qui est-ce qui dort ? → **Le chat**
    - **Marie et Lucie** jouent. → Qui est-ce qui joue ? → **Marie et Lucie**
    - **La pluie** tombe. → Qu'est-ce qui tombe ? → **La pluie**

### Cas particuliers

??? warning "Pieges a eviter"
    **Piege 1 : Sujet inverse**

    - Dans le jardin **jouent les enfants**. (Qui joue ? → les enfants)

    **Piege 2 : Sujet eloigne du verbe**

    - **Les oiseaux**, sur la branche, **chantent**. (Qui chante ? → les oiseaux)

    **Piege 3 : Sujet "qui"**

    - C'est moi **qui** ai gagne. (qui = moi → 1ere personne)

## Le COD (Complement d'Objet Direct)

Le **COD** complete le verbe **directement**, sans preposition.

### Comment le trouver ?

!!! note "Methode"
    Pose la question : **sujet + verbe + "qui ?"** ou **"quoi ?"**

!!! example "Exemples"
    - Je mange **une pomme**. → Je mange quoi ? → **une pomme** (COD)
    - Il regarde **son frere**. → Il regarde qui ? → **son frere** (COD)
    - Elle lit **un livre passionnant**. → Elle lit quoi ? → **un livre passionnant** (COD)

### Caracteristiques du COD

- Il est place **apres le verbe** (sauf si c'est un pronom)
- Il n'y a **pas de preposition** entre le verbe et le COD
- Il **complete** le sens du verbe

!!! warning "Attention"
    Certains verbes n'ont jamais de COD : aller, venir, partir, dormir...

    - Il **dort**. (pas de COD possible)
    - Elle **part**. (pas de COD possible)

---

## Le COI (Complement d'Objet Indirect)

Le **COI** complete le verbe **avec une preposition** (a, de, pour...).

### Comment le trouver ?

!!! note "Methode"
    Pose la question : **sujet + verbe + "a qui ?"**, **"a quoi ?"**, **"de qui ?"**, **"de quoi ?"**

!!! example "Exemples"
    - Je parle **a ma mere**. → Je parle a qui ? → **a ma mere** (COI)
    - Il pense **a ses vacances**. → Il pense a quoi ? → **a ses vacances** (COI)
    - Elle se souvient **de ce jour**. → Elle se souvient de quoi ? → **de ce jour** (COI)

### Difference COD / COI

| COD | COI |
|-----|-----|
| Sans preposition | Avec preposition (a, de...) |
| Question : "qui ?" ou "quoi ?" | Question : "a qui ?", "de quoi ?"... |
| Je mange **une pomme**. | Je parle **a Pierre**. |

---

## Les complements circonstanciels (CC)

Les **CC** indiquent les **circonstances** de l'action : ou, quand, comment, pourquoi...

### Les 4 types principaux

| Type | Question | Exemples |
|------|----------|----------|
| **CC de lieu** | Ou ? | Il joue **dans le jardin**. |
| **CC de temps** | Quand ? | Il viendra **demain**. |
| **CC de maniere** | Comment ? | Elle chante **doucement**. |
| **CC de cause** | Pourquoi ? | Il pleure **de joie**. |

### Caracteristiques des CC

!!! tip "Astuce"
    Les CC sont souvent :

    - **Deplacables** : *Demain*, je viendrai. / Je viendrai *demain*.
    - **Supprimables** : Je viendrai ~~demain~~. (la phrase reste correcte)

    Ce n'est pas le cas du COD ou du COI !

---

## Resume

| Fonction | Question | Exemple |
|----------|----------|---------|
| **Sujet** | Qui est-ce qui... ? | **Le chat** mange. |
| **COD** | ...quoi ? / ...qui ? | Il mange **la souris**. |
| **COI** | ...a qui ? / de quoi ? | Il parle **a Pierre**. |
| **CC lieu** | Ou ? | Il joue **dans le jardin**. |
| **CC temps** | Quand ? | Il vient **demain**. |
| **CC maniere** | Comment ? | Il parle **doucement**. |

## Exercices guides

### Exercice 1

!!! question "Trouve le sujet et le COD"
    "Marie mange une glace."

??? success "Correction"
    - Sujet : **Marie** (Qui est-ce qui mange ?)
    - COD : **une glace** (Marie mange quoi ?)

### Exercice 2

!!! question "Trouve la fonction des groupes soulignes"
    - a) **Pierre** joue au foot.
    - b) Il mange **un gateau**.
    - c) Elle parle **a son ami**.
    - d) Nous partons **demain**.

??? success "Correction"
    - a) Pierre = **sujet**
    - b) un gateau = **COD**
    - c) a son ami = **COI**
    - d) demain = **CC de temps**

## Entrainement

### Serie 1 : Facile

!!! note "Trouve le sujet de chaque phrase"
    1. Le chien aboie.
    2. Marie et Lucas jouent.
    3. Dans le ciel volent les oiseaux.

??? success "Corrections"
    1. **Le chien**
    2. **Marie et Lucas**
    3. **les oiseaux** (sujet inverse)

### Serie 2 : Moyen

!!! note "Trouve le COD ou le COI"
    1. Je lis un livre.
    2. Elle parle a sa soeur.
    3. Nous regardons la television.
    4. Il pense a ses vacances.

??? success "Corrections"
    1. un livre = **COD**
    2. a sa soeur = **COI**
    3. la television = **COD**
    4. a ses vacances = **COI**

### Serie 3 : Difficile

!!! note "Analyse complete"
    "Hier, Marie a offert un cadeau a son frere dans le salon."

??? success "Correction"
    - Hier = **CC de temps** (quand ?)
    - Marie = **sujet** (qui a offert ?)
    - a offert = **verbe**
    - un cadeau = **COD** (a offert quoi ?)
    - a son frere = **COI** (a offert a qui ?)
    - dans le salon = **CC de lieu** (ou ?)

## Evaluation

**Q1-Q5.** Trouve le sujet :

1. Les enfants jouent dans le jardin.
2. Demain, mes parents partiront en vacances.
3. Dans la foret vivent de nombreux animaux.

**Q6-Q10.** Trouve la fonction des groupes soulignes :

4. Il regarde **un film**.
5. Elle parle **a son professeur**.
6. Nous travaillons **le soir**.
7. Le chat mange **sa croquette**.
8. Je pense **a toi**.

??? success "Corrections"
    1. **Les enfants**
    2. **mes parents**
    3. **de nombreux animaux** (sujet inverse)
    4. un film = **COD**
    5. a son professeur = **COI**
    6. le soir = **CC de temps**
    7. sa croquette = **COD**
    8. a toi = **COI**

## Bilan

!!! summary "Ce que tu dois retenir"
    - **Sujet** : fait l'action → "Qui est-ce qui... ?"
    - **COD** : complete sans preposition → "...quoi ?" / "...qui ?"
    - **COI** : complete avec preposition → "...a qui ?" / "...de quoi ?"
    - **CC** : circonstances (deplacables, supprimables)
