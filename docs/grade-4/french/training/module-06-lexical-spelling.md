# Module 6 - Orthographe lexicale

!!! abstract "Objectifs"
    A la fin de ce module, tu sauras :

    - Trouver les lettres muettes grace aux mots de la meme famille
    - Reconnaitre les consonnes doubles
    - Ecrire correctement les mots courants

    **Duree estimee** : 1h30

---

## Les lettres muettes

### Lettres muettes finales

Beaucoup de mots francais se terminent par une **lettre qu'on n'entend pas**.

!!! tip "Astuce : cherche un mot de la meme famille"
    - gros → gro**sse** → gro**s**
    - lent → lent**e**, lent**eur** → len**t**
    - camp → camp**er**, camp**ement** → cam**p**
    - chat → chatt**e** → cha**t**

### Exemples courants

| Mot | Famille | Lettre muette |
|-----|---------|---------------|
| grand | grande, grandeur | **d** |
| petit | petite | **t** |
| long | longue, longueur | **g** |
| froid | froide | **d** |
| chaud | chaude, chaleur | **d** |
| blanc | blanche | **c** |

## Les consonnes doubles

### Quand doubler ?

!!! note "Quelques regles"
    **Apres a- :**
    - a**pp**eler, a**pp**rendre, a**pp**laudir
    - a**cc**order, a**cc**ompagner, o**cc**uper
    - a**ff**aire, e**ff**ort, di**ff**icile
    - a**tt**endre, a**tt**ention, a**tt**aquer

### Mots courants a doubles consonnes

| Lettre | Exemples |
|--------|----------|
| **ff** | effet, affaire, effort, different |
| **ll** | balle, belle, ville, fille |
| **mm** | homme, femme, comme, pomme |
| **nn** | annee, bonne, personne, donner |
| **pp** | appeler,apper, frapper |
| **rr** | arriver, terre, erreur |
| **ss** | classe, passer, aussi, reussir |
| **tt** | lettre, mettre, battre, attention |

## Le son [s] et le son [z]

### Le son [s]

| Graphie | Position | Exemples |
|---------|----------|----------|
| **s** | debut ou apres consonne | soir, personne |
| **ss** | entre deux voyelles | classe, reussir |
| **c** | devant e, i, y | ciel, cycle, cerise |
| **c** | devant a, o, u | ca, lecon, recu |
| **t** + ion | - | attention, nation |

### Le son [z]

| Graphie | Position | Exemples |
|---------|----------|----------|
| **z** | - | zero, douze |
| **s** | entre deux voyelles | maison, rose, musique |

!!! warning "Attention"
    Un seul **s** entre deux voyelles fait le son [z] !

    - poi**s**on [z] vs poi**ss**on [s]
    - de**s**ert [z] vs de**ss**ert [s]

---

## Mots invariables a connaitre

Ces mots ne changent jamais. Apprends-les par coeur !

| Categorie | Mots |
|-----------|------|
| **Temps** | toujours, jamais, souvent, parfois, alors, ensuite, enfin |
| **Lieu** | ici, la-bas, partout, ailleurs, dehors, dedans |
| **Quantite** | beaucoup, peu, assez, trop, tres, plus, moins |
| **Maniere** | bien, mal, vite, ainsi, comment |
| **Liaison** | mais, donc, car, parce que, cependant, pourtant |

## Exercices guides

### Exercice 1

!!! question "Trouve la lettre muette"
    1. gran... (grande)
    2. gri... (grise)
    3. len... (lente)

??? success "Correction"
    1. gran**d**
    2. gri**s**
    3. len**t**

### Exercice 2

!!! question "Simple ou double consonne ?"
    1. a...endre (attendre)
    2. a...iver (arriver)
    3. di...icile (difficile)

??? success "Correction"
    1. a**tt**endre
    2. a**rr**iver
    3. di**ff**icile

## Entrainement

### Serie 1 : Lettres muettes

!!! note "Trouve la lettre finale"
    1. Le cha... dort.
    2. C'est un lon... voyage.
    3. Il fait froi... dehors.
    4. Le san... coule.

??? success "Corrections"
    1. Le cha**t** dort.
    2. C'est un lon**g** voyage.
    3. Il fait froi**d** dehors.
    4. Le san**g** coule.

### Serie 2 : Sons [s] et [z]

!!! note "Complete avec s, ss, c ou c"
    1. La mai...on est grande.
    2. J'aime le de...ert au chocolat.
    3. Il fait une le...on de maths.
    4. Je connai... cette per...onne.

??? success "Corrections"
    1. La mai**s**on est grande. [z]
    2. J'aime le de**ss**ert au chocolat. [s]
    3. Il fait une le**c**on de maths. [s]
    4. Je connai**s** cette per**s**onne.

## Evaluation

!!! warning "A faire sans aide"

**Q1-Q5.** Ecris le mot avec sa lettre muette :

1. un renar... (renarde)
2. un blan... manteau (blanche)
3. un repo... (reposer)
4. un bon... (bonte)
5. le por... (porte)

**Q6-Q10.** Complete avec la bonne orthographe :

6. J'a...ends le bus. (attendre)
7. C'est di...icile. (difficile)
8. La cla...e commence. (classe)
9. Il est a...ive. (arriver)
10. Je fais un e...ort. (effort)

??? success "Corrections"
    1. un renar**d**
    2. un blan**c** manteau
    3. un repo**s**
    4. un bon**d** (bondir) ou bon**t** (selon le mot vise)
    5. le por**t**
    6. J'a**tt**ends le bus.
    7. C'est di**ff**icile.
    8. La cla**ss**e commence.
    9. Il est a**rr**ive.
    10. Je fais un e**ff**ort.

## Bilan

!!! summary "Ce que tu dois retenir"
    - **Lettres muettes** : cherche un mot de la meme famille
    - **Consonnes doubles** : souvent apres a- (app, acc, aff, att)
    - **s entre voyelles** = [z], **ss** = [s]
    - Apprends les mots invariables par coeur
