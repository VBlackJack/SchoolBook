## Le programme de Francais CM1

| Domaine | Themes principaux |
|---------|-------------------|
| **Grammaire** | Classes de mots (nom, verbe, adjectif, determinant, pronom), fonctions (sujet, COD, COI, CC) |
| **Conjugaison** | Present, imparfait, futur, passe compose, **passe simple** (nouveau !) |
| **Orthographe** | Accords sujet-verbe, accords dans le GN, homophones grammaticaux |
| **Vocabulaire** | Synonymes, antonymes, familles de mots, prefixes et suffixes |
| **Redaction** | Ecrire un recit, un dialogue, une description |

## Conseils pour progresser

!!! tip "Lis tous les jours"
    La lecture est le meilleur moyen d'ameliorer ton orthographe et ton vocabulaire. 15 minutes par jour suffisent !

!!! tip "Apprends tes conjugaisons"
    En CM1, tu dois maitriser les terminaisons du present, imparfait, futur et passe compose pour les verbes courants.

!!! tip "Relis-toi toujours"
    Avant de rendre un travail, relis-toi en verifiant : les accords, les homophones, la ponctuation.
