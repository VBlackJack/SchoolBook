# Orthographe

!!! info "Objectifs du chapitre"
    A la fin de ce chapitre, tu sauras :

    - Faire les accords dans le groupe nominal (determinant + nom + adjectif)
    - Faire l'accord sujet-verbe
    - Distinguer les homophones grammaticaux (a/a, et/est, son/sont...)
    - Appliquer les regles d'orthographe lexicale

---

## L'accord dans le groupe nominal

Le **groupe nominal** (GN) est compose d'un determinant, d'un nom et parfois d'adjectif(s).

!!! note "Regle d'or"
    Dans le GN, **tout s'accorde** avec le nom en **genre** (masculin/feminin) et en **nombre** (singulier/pluriel).

### Exemples

| Singulier | Pluriel |
|-----------|---------|
| **un** chat **noir** | **des** chat**s** **noir**s |
| **une** fleur **rouge** | **des** fleur**s** **rouge**s |
| **le** **petit** garcon | **les** **petit**s garcon**s** |
| **la** **grande** maison | **les** **grande**s maison**s** |

??? warning "Pieges a eviter"
    **Piege 1 : Adjectif de couleur**

    Les adjectifs de couleur simples s'accordent :

    - des fleurs **bleues**, des yeux **verts**

    Mais les couleurs issues de noms sont **invariables** :

    - des pulls **orange** (comme le fruit)
    - des jupes **marron** (comme la chataigne)

    ---

    **Piege 2 : Adjectif place avant le nom**

    L'adjectif s'accorde meme s'il est avant le nom :

    - de **belles** fleurs, de **grands** arbres

## L'accord sujet-verbe

!!! note "Regle d'or"
    Le verbe s'accorde toujours avec son **sujet** en personne et en nombre.

### Comment trouver le sujet ?

Pose la question : **"Qui est-ce qui + verbe ?"**

!!! example "Exemples"
    - Les enfants **jouent**. (Qui est-ce qui joue ? → Les enfants = ils = 3e pers. pluriel)
    - Marie et Lucie **chantent**. (Marie et Lucie = elles = 3e pers. pluriel)
    - Le chien de mes voisins **aboie**. (Qui aboie ? → Le chien = il = 3e pers. singulier)

??? warning "Pieges a eviter"
    **Piege 1 : Sujet eloigne du verbe**

    - Les oiseaux, dans le ciel, **chantent**. (pas "chante")

    **Piege 2 : Sujet inverse**

    - Dans le jardin **jouent** les enfants. (Qui joue ? → les enfants)

    **Piege 3 : Sujet "qui"**

    - C'est moi **qui** ai gagne. (qui = moi = 1ere pers.)
    - C'est toi **qui** as gagne. (qui = toi = 2e pers.)

## Les homophones grammaticaux

Les **homophones** sont des mots qui se prononcent pareil mais s'ecrivent differemment.

### a / a

| a (sans accent) | a (avec accent) |
|-----------------|-----------------|
| Verbe **avoir** au present (il/elle a) | Preposition |
| On peut remplacer par **avait** | On ne peut PAS remplacer par avait |

!!! example "Exemples"
    - Il **a** faim. → Il **avait** faim.
    - Je vais **a** Paris. → Je vais **avait** Paris.

---

### et / est

| et | est |
|----|-----|
| Conjonction de coordination | Verbe **etre** au present (il/elle est) |
| On peut remplacer par **et puis** | On peut remplacer par **etait** |

!!! example "Exemples"
    - Marie **et** Lucie jouent. → Marie **et puis** Lucie jouent.
    - Il **est** content. → Il **etait** content.

---

### son / sont

| son | sont |
|-----|------|
| Determinant possessif | Verbe **etre** au present (ils/elles sont) |
| On peut remplacer par **mon** | On peut remplacer par **etaient** |

!!! example "Exemples"
    - **Son** chien est gentil. → **Mon** chien est gentil.
    - Ils **sont** partis. → Ils **etaient** partis.

---

### on / ont

| on | ont |
|----|-----|
| Pronom personnel (= nous, quelqu'un) | Verbe **avoir** au present (ils/elles ont) |
| On peut remplacer par **il** | On peut remplacer par **avaient** |

!!! example "Exemples"
    - **On** joue au foot. → **Il** joue au foot.
    - Ils **ont** faim. → Ils **avaient** faim.

---

### ou / ou

| ou (sans accent) | ou (avec accent) |
|------------------|------------------|
| Conjonction (choix) | Adverbe de lieu |
| On peut remplacer par **ou bien** | On peut remplacer par **la-bas** |

!!! example "Exemples"
    - Tu veux une pomme **ou** une poire ? → **ou bien** une poire ?
    - **Ou** vas-tu ? → **La-bas** vas-tu ?

---

### ce / se

| ce | se |
|----|-----|
| Determinant demonstratif | Pronom reflexif (verbes pronominaux) |
| Devant un **nom** | Devant un **verbe** |

!!! example "Exemples"
    - **Ce** livre est interessant. (ce + nom)
    - Il **se** leve tot. (se + verbe pronominal)

---

### ces / ses

| ces | ses |
|-----|-----|
| Determinant demonstratif pluriel | Determinant possessif pluriel |
| On peut dire "ce... la" | On peut dire "son/sa" |

!!! example "Exemples"
    - **Ces** fleurs sont belles. → **Cette** fleur-la est belle.
    - Il a perdu **ses** cles. → Il a perdu **sa** cle.

---

## L'orthographe lexicale

### Les lettres muettes

Beaucoup de mots ont des lettres qu'on n'entend pas.

!!! tip "Astuce : cherche un mot de la meme famille"
    - gros → gro**sse** (donc gro**s**)
    - lent → lent**e**, lent**eur** (donc len**t**)
    - camp → camp**er**, camp**ement** (donc cam**p**)

### Les consonnes doubles

!!! example "Exemples courants"
    - a**pp**eler, a**pp**rendre, a**pp**laudir
    - a**cc**order, a**cc**ompagner, o**cc**uper
    - a**ff**aire, e**ff**ort, di**ff**icile
    - a**tt**endre, a**tt**ention, a**tt**aquer

---

## Resume : astuces pour les homophones

| Homophones | Astuce |
|------------|--------|
| a / a | a = avait / a = preposition |
| et / est | et = et puis / est = etait |
| son / sont | son = mon / sont = etaient |
| on / ont | on = il / ont = avaient |
| ou / ou | ou = ou bien / ou = la-bas |
| ce / se | ce + nom / se + verbe |
| ces / ses | ces = ce...la / ses = son/sa |

## Exercices

### Exercice 1 : Accords dans le GN

!!! question "Accorde les adjectifs"
    1. des fleurs (bleu)
    2. une maison (grand)
    3. les (petit) chats (noir)

??? success "Correction"
    1. des fleurs **bleues**
    2. une maison **grande** (ou une **grande** maison)
    3. les **petits** chats **noirs**

### Exercice 2 : Homophones a/a

!!! question "Complete avec a ou a"
    1. Elle ... mange une pomme.
    2. Je vais ... l'ecole.
    3. Mon frere ... dix ans.

??? success "Correction"
    1. Elle **a** mange une pomme. (avait)
    2. Je vais **a** l'ecole. (preposition)
    3. Mon frere **a** dix ans. (avait)

### Exercice 3 : Homophones son/sont

!!! question "Complete avec son ou sont"
    1. ... cahier est rouge.
    2. Ils ... partis hier.
    3. Elle a perdu ... stylo.

??? success "Correction"
    1. **Son** cahier est rouge. (mon)
    2. Ils **sont** partis hier. (etaient)
    3. Elle a perdu **son** stylo. (mon)
