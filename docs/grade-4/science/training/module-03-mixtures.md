# Module 3 - Les melanges

!!! abstract "Objectifs"
    - Distinguer melange homogene et heterogene
    - Connaitre les techniques de separation
    - Realiser des experiences de melanges

    **Duree** : 1 heure

---

## Qu'est-ce qu'un melange ?

!!! note "Definition"
    Un **melange** est l'association de plusieurs substances.

---

## Les 2 types de melanges

### Melange homogene

!!! note "Definition"
    Un melange **homogene** est un melange ou on ne distingue pas les composants a l'oeil nu.

| Melange | Composants |
|---------|------------|
| Eau sucree | Eau + sucre |
| Eau salee | Eau + sel |
| Sirop | Eau + sirop |
| Air | Azote + oxygene + autres gaz |

!!! example "Experience"
    Dissous du sucre dans l'eau : tu ne vois plus le sucre, mais il est toujours la !

### Melange heterogene

!!! note "Definition"
    Un melange **heterogene** est un melange ou on distingue les composants a l'oeil nu.

| Melange | Composants |
|---------|------------|
| Eau + huile | 2 couches visibles |
| Eau + sable | Sable visible au fond |
| Salade composee | Differents ingredients visibles |

!!! example "Experience"
    Melange de l'eau et de l'huile : deux couches se forment.

---

## Tableau comparatif

| Critere | Homogene | Heterogene |
|---------|----------|------------|
| Aspect | Uniforme | Non uniforme |
| Composants | Invisibles | Visibles |
| Exemple | Eau + sel | Eau + huile |

---

## Separer les melanges

### La decantation

!!! note "Definition"
    Laisser reposer pour que les composants se separent.

**Utilisation** : melanges heterogenes (eau + sable)

### La filtration

!!! note "Definition"
    Passer le melange dans un filtre qui retient les particules solides.

**Utilisation** : eau + sable, cafe

### L'evaporation

!!! note "Definition"
    Chauffer pour faire evaporer le liquide et recuperer le solide.

**Utilisation** : eau salee → recuperer le sel

### Tableau recapitulatif

| Technique | Principe | Exemple |
|-----------|----------|---------|
| **Decantation** | Laisser reposer | Eau + terre |
| **Filtration** | Filtre les solides | Cafe |
| **Evaporation** | Evapore le liquide | Sel marin |

---

## La dissolution

!!! note "Definition"
    La **dissolution** est le phenomene ou un solide "disparait" dans un liquide.

### Vocabulaire

| Terme | Definition | Exemple |
|-------|------------|---------|
| **Solute** | Ce qui se dissout | Sucre |
| **Solvant** | Ce qui dissout | Eau |
| **Solution** | Le melange obtenu | Eau sucree |

### Facteurs qui accelerent la dissolution

- **Temperature** : l'eau chaude dissout mieux
- **Agitation** : remuer accelere la dissolution
- **Taille** : sucre en poudre se dissout plus vite que morceaux

---

## Exercices

!!! question "Q1. L'eau + sirop est-il un melange homogene ou heterogene ?"

??? success "Correction"
    **Homogene** (on ne voit pas le sirop dissous)

!!! question "Q2. Quelle technique utiliser pour separer l'eau et le sable ?"

??? success "Correction"
    **Filtration** ou **decantation**

!!! question "Q3. Comment recuperer le sel de l'eau de mer ?"

??? success "Correction"
    Par **evaporation** (le sel reste quand l'eau s'evapore)

!!! question "Q4. Dans une solution d'eau sucree, quel est le solvant ?"

??? success "Correction"
    L'**eau** (c'est elle qui dissout le sucre)

---

!!! summary "Bilan"
    - **Homogene** : composants invisibles (eau + sel)
    - **Heterogene** : composants visibles (eau + huile)
    - Techniques de separation : **decantation, filtration, evaporation**
    - Dissolution : solute + solvant = solution
