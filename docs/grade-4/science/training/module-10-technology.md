## Les objets techniques

### Definition

!!! note "Definition"
    Un **objet technique** est un objet fabrique par l'homme pour repondre a un besoin.

### Exemples

| Besoin | Objet technique |
|--------|-----------------|
| Se deplacer | Velo, voiture |
| Communiquer | Telephone |
| S'eclairer | Lampe |
| Ecrire | Stylo |

### Fonction d'un objet

| Terme | Definition |
|-------|------------|
| **Fonction d'usage** | A quoi sert l'objet |
| **Fonction technique** | Comment l'objet fonctionne |

!!! example "Exemple : le velo"
    - Fonction d'usage : se deplacer
    - Fonctions techniques : rouler (roues), diriger (guidon), freiner (freins)

## L'electricite

### Qu'est-ce que l'electricite ?

!!! note "Definition"
    L'**electricite** est une forme d'energie qui peut produire lumiere, chaleur, mouvement.

### Les sources d'electricite

| Source | Type |
|--------|------|
| **Piles** | Portable, limitee |
| **Prises** | Reseau electrique |
| **Panneaux solaires** | Energie du soleil |
| **Eoliennes** | Energie du vent |

---

## Le circuit electrique

### Les composants de base

| Composant | Role | Symbole |
|-----------|------|---------|
| **Pile/Generateur** | Fournit l'electricite | —\|+ |
| **Fil electrique** | Transporte l'electricite | — |
| **Ampoule** | Produit de la lumiere | ⊗ |
| **Interrupteur** | Ouvre/ferme le circuit | —/— |

### Circuit ouvert et ferme

| Etat | Description | Ampoule |
|------|-------------|---------|
| **Ferme** | Le courant passe | Allumee |
| **Ouvert** | Le courant ne passe pas | Eteinte |

!!! tip "A retenir"
    Pour que l'ampoule s'allume, le circuit doit etre **ferme** (complet).

---

## Conducteurs et isolants

### Definition

| Type | Definition | Exemples |
|------|------------|----------|
| **Conducteur** | Laisse passer l'electricite | Cuivre, fer, aluminium |
| **Isolant** | Bloque l'electricite | Plastique, bois, verre |

### Pourquoi c'est important ?

- Les **fils** sont en cuivre (conducteur)
- Les **gaines** sont en plastique (isolant) → securite !

---

## Securite electrique

### Les dangers

!!! danger "Attention !"
    L'electricite des prises (220V) est **dangereuse** !
    Elle peut provoquer :
    - Electrocution
    - Brulures
    - Incendies

### Les regles de securite

| Regle | Explication |
|-------|-------------|
| Ne jamais mettre les doigts dans une prise | Electrocution |
| Ne pas utiliser d'appareil mouille | L'eau conduit l'electricite |
| Ne pas tirer sur les fils | Risque de court-circuit |
| Faire appel a un adulte | Pour toute manipulation |

## Experience : realiser un circuit

!!! example "Materiel"
    - 1 pile plate (4,5V)
    - 1 ampoule avec douille
    - 2 fils electriques
    - 1 interrupteur

### Etapes

1. Connecte un fil de la pile a l'ampoule
2. Connecte l'ampoule a l'interrupteur
3. Connecte l'interrupteur a la pile
4. Ferme l'interrupteur : l'ampoule s'allume !

## Exercices

!!! question "Q1. Qu'est-ce qu'un objet technique ?"

??? success "Correction"
    Un objet **fabrique par l'homme** pour repondre a un **besoin**

!!! question "Q2. Cite 2 materiaux conducteurs"

??? success "Correction"
    Cuivre, fer, aluminium, or, argent (2 parmi ces reponses)

!!! question "Q3. Pourquoi une ampoule ne s'allume-t-elle pas si le circuit est ouvert ?"

??? success "Correction"
    Parce que le courant **ne peut pas circuler** (le circuit est interrompu)

!!! question "Q4. Pourquoi les fils electriques sont-ils entoures de plastique ?"

??? success "Correction"
    Pour **isoler** et eviter les electrocutions (le plastique est isolant)

    - Circuit electrique : generateur + fils + recepteur
    - Circuit **ferme** = courant passe, circuit **ouvert** = courant bloque
    - **Conducteurs** (metaux) vs **isolants** (plastique)
    - L'electricite est **dangereuse** : respecter les regles de securite
