# Le vivant

## Les fonctions vitales

### Qu'est-ce qu'un etre vivant ?

Un etre vivant :

- **Nait** (ou germe)
- **Se nourrit**
- **Grandit**
- **Se reproduit**
- **Meurt**

### Les grandes fonctions

| Fonction | Role | Organes |
|----------|------|---------|
| **Nutrition** | Se nourrir, respirer | Bouche, poumons, estomac |
| **Relation** | Percevoir, reagir | Yeux, oreilles, cerveau |
| **Reproduction** | Creer de nouveaux etres | Organes reproducteurs |

---

## La digestion

### Le trajet des aliments

1. **Bouche** : mastication, salive
2. **Oesophage** : transport
3. **Estomac** : broyage, sucs gastriques
4. **Intestin grele** : absorption des nutriments
5. **Gros intestin** : absorption de l'eau
6. **Rectum** : evacuation des dechets

!!! note "A retenir"
    La digestion transforme les aliments en **nutriments** utilisables par le corps.

---

## La respiration

### Les echanges gazeux

| Inspiration | Expiration |
|-------------|------------|
| Air entre (oxygene) | Air sort (dioxyde de carbone) |

### Le trajet de l'air

1. **Nez/Bouche** : entree de l'air
2. **Trachee** : conduit
3. **Bronches** : division en deux
4. **Poumons** : echanges gazeux

---

## La reproduction

### Reproduction des animaux

| Type | Caracteristiques | Exemples |
|------|------------------|----------|
| **Ovipare** | Nait dans un oeuf | Poule, poisson |
| **Vivipare** | Nait du ventre de la mere | Chat, humain |

### Reproduction des plantes

| Type | Description |
|------|-------------|
| **Par graines** | Pollinisation → fruit → graine |
| **Vegetative** | Bouturage, marcottage |

---

## La classification du vivant

### Les grands groupes

| Groupe | Caracteristiques | Exemples |
|--------|------------------|----------|
| **Vertebres** | Squelette interne | Mammiferes, oiseaux, poissons |
| **Invertebres** | Pas de squelette interne | Insectes, vers, mollusques |

### Les vertebres

| Classe | Caracteristiques |
|--------|------------------|
| **Mammiferes** | Poils, allaitement |
| **Oiseaux** | Plumes, bec |
| **Reptiles** | Ecailles, sang froid |
| **Amphibiens** | Peau nue, sang froid |
| **Poissons** | Ecailles, branchies |

## Exercices

!!! question "Q1. Cite les 5 caracteristiques d'un etre vivant"

??? success "Correction"
    Naitre, se nourrir, grandir, se reproduire, mourir

!!! question "Q2. Ou se passe l'absorption des nutriments ?"

??? success "Correction"
    Dans l'**intestin grele**

!!! question "Q3. Est-ce qu'un chat est ovipare ou vivipare ?"
