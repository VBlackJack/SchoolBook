## Droite, segment, demi-droite

### La droite

!!! note "Definition"
    Une **droite** est une ligne qui n'a **ni debut ni fin**.
    Elle se prolonge a l'infini des deux cotes.

```
←─────────────────────────────────────────→
         Droite (infinie des 2 cotes)
```

On nomme une droite avec une lettre entre parentheses : **(d)** ou **(D)**

Ou avec deux points : **(AB)**

### Le segment

!!! note "Definition"
    Un **segment** est une partie de droite **limitee par 2 points**.
    Il a un debut et une fin.

```
    A●─────────────────────●B
              Segment [AB]
```

On note un segment avec des crochets : **[AB]**

La **longueur** d'un segment se mesure en cm, m, km...

### La demi-droite

!!! note "Definition"
    Une **demi-droite** a une **origine** (un debut) mais **pas de fin**.
    Elle se prolonge a l'infini d'un seul cote.

```
    A●─────────────────────────────────→
         Demi-droite [AB)
```

On note une demi-droite : **[AB)** (A est l'origine)

### Comparaison

| Type | Debut | Fin | Notation |
|------|:-----:|:---:|----------|
| **Droite** | Non | Non | (d) ou (AB) |
| **Segment** | Oui | Oui | [AB] |
| **Demi-droite** | Oui | Non | [AB) |

## Les droites perpendiculaires

### Definition

!!! note "A retenir"
    Deux droites sont **perpendiculaires** si elles se coupent en formant un **angle droit** (90°).

```
            │
            │
            │
────────────┼────────────
            │
            │
            │
```

On note : **(d1) ⊥ (d2)** (se lit "d1 perpendiculaire a d2")

### Comment verifier ?

!!! tip "Utilise l'equerre"
    1. Place un cote de l'equerre sur une droite
    2. L'autre cote doit etre exactement sur l'autre droite
    3. Si ca correspond, les droites sont perpendiculaires !

### Comment tracer ?

!!! note "Methode"
    1. Trace une premiere droite
    2. Place l'equerre sur cette droite
    3. Trace la deuxieme droite le long de l'autre cote de l'equerre

---

## Les droites paralleles

### Definition

!!! note "A retenir"
    Deux droites sont **paralleles** si elles ne se coupent **jamais**.
    Elles gardent toujours le meme ecart.

```
─────────────────────────────────────
                                       (d1)
─────────────────────────────────────
                                       (d2)
```

On note : **(d1) // (d2)** (se lit "d1 parallele a d2")

### Comment verifier ?

!!! tip "Utilise l'equerre et la regle"
    1. Trace une perpendiculaire aux deux droites
    2. Mesure l'ecart entre les droites a plusieurs endroits
    3. Si l'ecart est toujours le meme, elles sont paralleles !

### Propriete importante

!!! warning "A retenir"
    Si deux droites sont **perpendiculaires a une meme droite**, alors elles sont **paralleles entre elles**.

```
        │
────────┼────────  (d1)
        │
────────┼────────  (d2)
        │
       (d3)

(d1) ⊥ (d3) et (d2) ⊥ (d3) donc (d1) // (d2)
```

## Les outils de geometrie

### La regle

!!! note "Utilisation"
    - Tracer des **droites** et des **segments**
    - **Mesurer** des longueurs
    - Verifier l'alignement de points

### L'equerre

!!! note "Utilisation"
    - Tracer des **angles droits**
    - Verifier si deux droites sont **perpendiculaires**
    - Tracer des **droites paralleles**

### Le compas

!!! note "Utilisation"
    - Tracer des **cercles**
    - **Reporter** des longueurs
    - Tracer des **arcs de cercle**

## Les pieges a eviter

!!! warning "Piege 1 : Confondre droite et segment"
    - Une **droite** est infinie (pas de bout)
    - Un **segment** a deux bouts bien definis

!!! warning "Piege 2 : Perpendiculaire ≠ qui se croisent"
    Deux droites peuvent se croiser sans etre perpendiculaires !
    Il faut que l'angle soit **exactement 90°**.

!!! warning "Piege 3 : Paralleles = meme direction"
    Des droites paralleles ne se rencontrent **jamais**, meme prolongees a l'infini.

## Exercices guides

### Exercice 1 : Identifier

!!! question "Droite, segment ou demi-droite ?"
    1. Une ligne avec deux points aux extremites
    2. Une ligne avec des fleches aux deux bouts
    3. Une ligne avec un point d'un cote et une fleche de l'autre

??? success "Correction"
    1. **Segment**
    2. **Droite**
    3. **Demi-droite**

### Exercice 2 : Perpendiculaires

!!! question "Ces droites sont-elles perpendiculaires ?"
    1. Les bords d'une feuille de papier
    2. Les aiguilles d'une montre a 15h00
    3. Les diagonales d'un carre

??? success "Correction"
    1. **Oui** - Les bords forment des angles droits
    2. **Oui** - A 15h, les aiguilles forment un angle de 90°
    3. **Oui** - Les diagonales d'un carre sont perpendiculaires

### Exercice 3 : Paralleles

!!! question "Ces droites sont-elles paralleles ?"
    1. Les deux rails d'une voie ferree
    2. Les lignes d'une feuille a carreaux (horizontales)
    3. Les deux cotes opposes d'un rectangle

??? success "Correction"
    1. **Oui** - Les rails gardent le meme ecart
    2. **Oui** - Les lignes ne se coupent jamais
    3. **Oui** - Les cotes opposes d'un rectangle sont paralleles

## Entrainement

### Serie 1 : Vocabulaire

!!! note "Complete"
    1. Une droite est ...... des deux cotes.
    2. Un segment a ...... extremites.
    3. Deux droites perpendiculaires forment un angle de ......
    4. Deux droites paralleles ne se ...... jamais.

??? success "Corrections"
    1. **infinie**
    2. **deux**
    3. **90°** (ou angle droit)
    4. **coupent** (ou croisent)

### Serie 2 : Notation

!!! note "Ecris la notation correcte"
    1. Segment de A a B
    2. Droite passant par C et D
    3. Demi-droite d'origine E passant par F

??? success "Corrections"
    1. **[AB]**
    2. **(CD)** ou **(d)**
    3. **[EF)**

### Serie 3 : Vrai ou Faux

!!! note "Reponds"
    1. Une droite a une longueur qu'on peut mesurer.
    2. Deux droites perpendiculaires se coupent.
    3. Deux droites paralleles ont le meme ecart partout.
    4. Un segment peut etre prolonge en droite.

??? success "Corrections"
    1. **Faux** - Une droite est infinie
    2. **Vrai** - Elles se coupent en formant un angle droit
    3. **Vrai** - C'est la definition
    4. **Vrai** - On peut toujours prolonger un segment
