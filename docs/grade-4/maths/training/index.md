# Formation Complete - Mathematiques CM1

!!! info "Bienvenue dans la formation complete !"
    Cette formation te guidera a travers tout le programme de mathematiques de CM1.

    **10 modules progressifs** pour maitriser les maths !

## Comment ca marche ?

1. **Commence par le Module 0** : Test de positionnement pour evaluer ton niveau
2. **Suis les modules dans l'ordre** : Chaque module s'appuie sur le precedent
3. **Valide chaque module** : Obtiens au moins 14/20 pour passer au suivant
