# Module 8 - Les nombres decimaux

!!! info "Objectifs du module"
    A la fin de ce module, tu sauras :

    - Lire et ecrire des nombres decimaux
    - Comprendre le tableau de numeration
    - Comparer et ranger des nombres decimaux

    **Duree estimee : 2-3 heures** | **Pre-requis : Module 7**

## Qu'est-ce qu'un nombre decimal ?

### Definition

!!! note "A retenir"
    Un **nombre decimal** est un nombre qui comporte une **virgule**.

    Il a une **partie entiere** (avant la virgule) et une **partie decimale** (apres la virgule).

### Exemple : 12,47

| Partie entiere | Virgule | Partie decimale |
|----------------|---------|-----------------|
| 12 | , | 47 |
| douze | | quarante-sept centiemes |

## Le tableau de numeration

### Les rangs

| Centaines | Dizaines | Unites | , | Dixiemes | Centiemes |
|-----------|----------|--------|---|----------|-----------|
| 100 | 10 | 1 | , | 0,1 | 0,01 |
| C | D | U | , | d | c |

### Exemple : 325,48

| C | D | U | , | d | c |
|---|---|---|---|---|---|
| 3 | 2 | 5 | , | 4 | 8 |

- **3** centaines = 300
- **2** dizaines = 20
- **5** unites = 5
- **4** dixiemes = 0,4
- **8** centiemes = 0,08

Donc : 325,48 = 300 + 20 + 5 + 0,4 + 0,08

## Lire et ecrire des nombres decimaux

### Lire un nombre decimal

!!! note "Methode"
    1. Lire la partie entiere
    2. Dire "virgule"
    3. Lire la partie decimale chiffre par chiffre OU en entier

| Nombre | Lecture (methode 1) | Lecture (methode 2) |
|--------|---------------------|---------------------|
| 3,7 | trois virgule sept | trois et sept dixiemes |
| 15,24 | quinze virgule vingt-quatre | quinze et vingt-quatre centiemes |
| 0,05 | zero virgule zero cinq | cinq centiemes |

### Attention aux zeros !

!!! warning "Pieges a eviter"
    - 3,5 = 3,50 (trois et cinq dixiemes)
    - 3,05 ≠ 3,5 (trois et cinq **centiemes** ≠ cinq **dixiemes**)
    - 0,7 = 0,70 mais ≠ 0,07

| Nombre | Valeur | Attention |
|--------|--------|-----------|
| 3,5 | 3 + 0,5 | = 3,50 |
| 3,05 | 3 + 0,05 | ≠ 3,5 ! |
| 0,7 | 0 + 0,7 | = 0,70 |
| 0,07 | 0 + 0,07 | ≠ 0,7 ! |

## Comparer des nombres decimaux

### Methode

!!! note "Comment comparer ?"
    1. Compare d'abord les **parties entieres**
    2. Si elles sont egales, compare les **dixiemes**
    3. Si egaux, compare les **centiemes**

### Exemples

| Comparaison | Explication |
|-------------|-------------|
| 5,7 > 4,9 | 5 > 4 (parties entieres) |
| 3,8 > 3,2 | 3 = 3, mais 8 > 2 (dixiemes) |
| 7,45 > 7,39 | 7 = 7, 4 > 3 (dixiemes) |
| 2,53 < 2,58 | 2 = 2, 5 = 5, mais 3 < 8 (centiemes) |

!!! tip "Astuce"
    Ajoute des zeros pour avoir le meme nombre de chiffres :

    Comparer 3,5 et 3,48 → comparer 3,50 et 3,48

    Donc **3,5 > 3,48** car 50 > 48

## Ranger des nombres decimaux

### Ordre croissant (du plus petit au plus grand)

!!! example "Exemple"
    Range dans l'ordre croissant : 4,7 ; 4,25 ; 4,08 ; 4,5

    1. Aligne les parties decimales : 4,70 ; 4,25 ; 4,08 ; 4,50
    2. Compare : 08 < 25 < 50 < 70
    3. Resultat : **4,08 < 4,25 < 4,5 < 4,7**

### Ordre decroissant (du plus grand au plus petit)

!!! example "Exemple"
    Range dans l'ordre decroissant : 3,2 ; 3,15 ; 3,9

    1. Aligne : 3,20 ; 3,15 ; 3,90
    2. Compare : 90 > 20 > 15
    3. Resultat : **3,9 > 3,2 > 3,15**

## Encadrer des nombres decimaux

### Entre deux entiers

!!! note "Methode"
    On cherche les deux entiers **consecutifs** qui encadrent le nombre.

| Nombre | Encadrement |
|--------|-------------|
| 3,7 | 3 < 3,7 < 4 |
| 12,45 | 12 < 12,45 < 13 |
| 0,8 | 0 < 0,8 < 1 |

### Entre deux dixiemes

| Nombre | Encadrement |
|--------|-------------|
| 3,74 | 3,7 < 3,74 < 3,8 |
| 5,08 | 5,0 < 5,08 < 5,1 |

## Placer sur une droite graduee

### Methode

Pour placer 2,7 :

1. Repere 2 et 3 sur la droite
2. Divise l'intervalle en 10 parts
3. Compte 7 graduations depuis 2

```
2,0   2,1   2,2   2,3   2,4   2,5   2,6   2,7   2,8   2,9   3,0
|-----|-----|-----|-----|-----|-----|-----|-----|-----|-----|
                                          ^
                                         2,7
```

## Calculs avec les decimaux

### Addition

!!! note "Methode"
    Aligne les **virgules** les unes sous les autres !

```
    12,45
  +  3,72
  -------
    16,17
```

### Soustraction

!!! note "Methode"
    Meme principe : aligne les virgules !

```
    25,80
  -  8,35
  -------
    17,45
```

!!! tip "Astuce"
    Ajoute des zeros si necessaire :

    15,4 - 3,25 → calcule 15,40 - 3,25

## Exercices guides

### Exercice 1 : Lire

!!! question "Lis ces nombres decimaux"
    1. 7,3
    2. 12,08
    3. 0,45

??? success "Correction"
    1. Sept virgule trois (ou sept et trois dixiemes)
    2. Douze virgule zero huit (ou douze et huit centiemes)
    3. Zero virgule quarante-cinq (ou quarante-cinq centiemes)

### Exercice 2 : Comparer

!!! question "Compare avec < ou >"
    1. 5,8 ... 5,3
    2. 4,15 ... 4,7
    3. 3,5 ... 3,50

??? success "Correction"
    1. 5,8 **>** 5,3
    2. 4,15 **<** 4,7 (4,15 < 4,70)
    3. 3,5 **=** 3,50

### Exercice 3 : Calculer

!!! question "Calcule"
    1. 4,5 + 2,3
    2. 8,7 - 3,4

??? success "Correction"
    1. 4,5 + 2,3 = **6,8**
    2. 8,7 - 3,4 = **5,3**

## Entrainement

### Serie 1 : Comparaison

!!! note "Compare avec <, > ou ="
    1. 6,4 ... 6,09
    2. 3,50 ... 3,5
    3. 8,25 ... 8,3
    4. 0,9 ... 0,90

??? success "Corrections"
    1. 6,4 > 6,09 (6,40 > 6,09)
    2. 3,50 = 3,5
    3. 8,25 < 8,3 (8,25 < 8,30)
    4. 0,9 = 0,90

### Serie 2 : Ranger

!!! note "Range dans l'ordre croissant"
    1. 2,5 ; 2,15 ; 2,8 ; 2,05
    2. 7,3 ; 7,09 ; 7,35 ; 7,1

??? success "Corrections"
    1. 2,05 < 2,15 < 2,5 < 2,8
    2. 7,09 < 7,1 < 7,3 < 7,35

### Serie 3 : Calculs

!!! note "Calcule"
    1. 5,6 + 3,8
    2. 12,45 + 7,3
    3. 9,5 - 4,2
    4. 15,3 - 8,75

??? success "Corrections"
    1. 5,6 + 3,8 = 9,4
    2. 12,45 + 7,30 = 19,75
    3. 9,5 - 4,2 = 5,3
    4. 15,30 - 8,75 = 6,55
