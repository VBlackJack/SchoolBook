# Module 6 - Fractions simples

!!! info "Objectifs du module"
    A la fin de ce module, tu sauras :

    - Comprendre ce qu'est une fraction
    - Identifier numerateur et denominateur
    - Connaitre les fractions usuelles (1/2, 1/4, 3/4)
    - Placer des fractions sur une droite graduee
    - Comparer des fractions simples

    **Duree estimee : 2-3 heures** | **Pre-requis : Module 5**

---

## Qu'est-ce qu'une fraction ?

### Definition

!!! note "A retenir"
    Une **fraction** represente une partie d'un tout.

    Elle s'ecrit avec deux nombres separes par un trait :

    $$\frac{numerateur}{denominateur}$$

### Les deux parties d'une fraction

| Element | Position | Signification |
|---------|----------|---------------|
| **Numerateur** | En haut | Nombre de parts qu'on prend |
| **Denominateur** | En bas | Nombre total de parts egales |

!!! example "Exemple"
    $\frac{3}{4}$ se lit "**trois quarts**"

    - Le denominateur **4** : on a coupe en 4 parts egales
    - Le numerateur **3** : on prend 3 de ces parts

---

## Les fractions usuelles

### Le demi (1/2)

!!! note "Un demi"
    $\frac{1}{2}$ = **la moitie**

    On coupe en **2 parts egales**, on en prend **1**.

| Objet | Un demi |
|-------|---------|
| Une pizza | La moitie de la pizza |
| 1 heure | 30 minutes |
| 1 metre | 50 centimetres |

### Le quart (1/4)

!!! note "Un quart"
    $\frac{1}{4}$ = **un quart**

    On coupe en **4 parts egales**, on en prend **1**.

| Objet | Un quart |
|-------|----------|
| Une pizza | 1 part sur 4 |
| 1 heure | 15 minutes |
| 1 metre | 25 centimetres |

### Le tiers (1/3)

!!! note "Un tiers"
    $\frac{1}{3}$ = **un tiers**

    On coupe en **3 parts egales**, on en prend **1**.

### Recapitulatif

| Fraction | Nom | Signification |
|----------|-----|---------------|
| $\frac{1}{2}$ | Un demi | 1 part sur 2 |
| $\frac{1}{3}$ | Un tiers | 1 part sur 3 |
| $\frac{1}{4}$ | Un quart | 1 part sur 4 |
| $\frac{2}{3}$ | Deux tiers | 2 parts sur 3 |
| $\frac{3}{4}$ | Trois quarts | 3 parts sur 4 |

## Lire et ecrire des fractions

### Comment lire ?

| Fraction | Lecture |
|----------|---------|
| $\frac{1}{2}$ | un demi |
| $\frac{1}{3}$ | un tiers |
| $\frac{1}{4}$ | un quart |
| $\frac{2}{5}$ | deux cinquiemes |
| $\frac{3}{8}$ | trois huitiemes |
| $\frac{7}{10}$ | sept dixiemes |

!!! tip "Astuce"
    A partir de 5, on ajoute **-ieme** au denominateur :

    - 5 → cinqu**ieme**
    - 6 → six**ieme**
    - 10 → dix**ieme**

## Representer des fractions

### Sur une figure

Pour representer $\frac{3}{4}$ :

1. Dessine une forme (carre, cercle, rectangle)
2. Divise-la en **4 parts egales** (denominateur)
3. Colorie **3 parts** (numerateur)

### Sur une droite graduee

Pour placer $\frac{3}{4}$ sur une droite :

```
0        1/4       2/4       3/4        1
|---------|---------|---------|---------|
                              ^
                           3/4 ici
```

!!! note "Methode"
    1. Repere 0 et 1
    2. Divise en autant de parts que le denominateur (ici 4)
    3. Compte le nombre de parts indique par le numerateur (ici 3)

## Fractions egales a 1

!!! warning "Important"
    Quand le numerateur = denominateur, la fraction vaut **1** (un entier).

| Fraction | Valeur |
|----------|--------|
| $\frac{2}{2}$ | 1 |
| $\frac{3}{3}$ | 1 |
| $\frac{4}{4}$ | 1 |
| $\frac{10}{10}$ | 1 |

---

## Comparer des fractions

### Meme denominateur

!!! note "Regle"
    Si les fractions ont le **meme denominateur**, on compare les **numerateurs**.

| Comparaison | Explication |
|-------------|-------------|
| $\frac{3}{5} > \frac{2}{5}$ | 3 > 2, donc 3/5 est plus grand |
| $\frac{1}{4} < \frac{3}{4}$ | 1 < 3, donc 1/4 est plus petit |

### Comparer a 1

| Si... | Alors la fraction est... |
|-------|--------------------------|
| numerateur < denominateur | **inferieure a 1** |
| numerateur = denominateur | **egale a 1** |
| numerateur > denominateur | **superieure a 1** |

!!! example "Exemples"
    - $\frac{3}{4}$ : 3 < 4, donc $\frac{3}{4}$ < 1
    - $\frac{5}{5}$ : 5 = 5, donc $\frac{5}{5}$ = 1
    - $\frac{7}{4}$ : 7 > 4, donc $\frac{7}{4}$ > 1

## Exercices guides

### Exercice 1 : Identifier

!!! question "Donne le numerateur et le denominateur"
    1. $\frac{3}{5}$
    2. $\frac{7}{10}$
    3. $\frac{1}{2}$

??? success "Correction"
    1. Numerateur : **3**, Denominateur : **5**
    2. Numerateur : **7**, Denominateur : **10**
    3. Numerateur : **1**, Denominateur : **2**

### Exercice 2 : Lire

!!! question "Ecris en lettres"
    1. $\frac{1}{4}$
    2. $\frac{2}{3}$
    3. $\frac{5}{8}$

??? success "Correction"
    1. **un quart**
    2. **deux tiers**
    3. **cinq huitiemes**

### Exercice 3 : Comparer

!!! question "Compare avec < ou >"
    1. $\frac{2}{5}$ ... $\frac{4}{5}$
    2. $\frac{3}{4}$ ... $\frac{1}{4}$
    3. $\frac{5}{6}$ ... 1

??? success "Correction"
    1. $\frac{2}{5}$ **<** $\frac{4}{5}$
    2. $\frac{3}{4}$ **>** $\frac{1}{4}$
    3. $\frac{5}{6}$ **<** 1 (car 5 < 6)

## Entrainement

### Serie 1 : Numerateur et denominateur

!!! note "Identifie"
    Pour chaque fraction, donne le numerateur et le denominateur :

    1. $\frac{4}{7}$
    2. $\frac{9}{10}$
    3. $\frac{6}{6}$
    4. $\frac{11}{12}$

??? success "Corrections"
    1. N = 4, D = 7
    2. N = 9, D = 10
    3. N = 6, D = 6 (cette fraction vaut 1)
    4. N = 11, D = 12

### Serie 2 : Lecture

!!! note "Ecris en lettres"
    1. $\frac{1}{3}$
    2. $\frac{3}{4}$
    3. $\frac{7}{10}$
    4. $\frac{5}{6}$

??? success "Corrections"
    1. un tiers
    2. trois quarts
    3. sept dixiemes
    4. cinq sixiemes

### Serie 3 : Comparaison

!!! note "Compare avec <, > ou ="
    1. $\frac{1}{3}$ ... $\frac{2}{3}$
    2. $\frac{5}{5}$ ... 1
    3. $\frac{7}{8}$ ... $\frac{3}{8}$
    4. $\frac{4}{5}$ ... 1

??? success "Corrections"
    1. $\frac{1}{3}$ < $\frac{2}{3}$
    2. $\frac{5}{5}$ = 1
    3. $\frac{7}{8}$ > $\frac{3}{8}$
    4. $\frac{4}{5}$ < 1

!!! summary "Bilan"
    - **Fraction** = numerateur / denominateur
