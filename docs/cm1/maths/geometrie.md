## Vocabulaire de base

### Dans la vraie vie : la geometrie partout !

!!! tip "Tu utilises deja la geometrie sans le savoir !"

    **Dans les jeux video :**

    - Dans Minecraft, tout est fait de **cubes** et de **carres** !
    - Les cartes de jeux de cartes sont des **rectangles**
    - La balle de foot dans FIFA est faite de **pentagones** et **hexagones**

    **Dans le sport :**

    - Un terrain de foot est un **rectangle**
    - Le cercle central a un **rayon** de 9,15 m
    - Les buts forment des **rectangles**

    **Autour de toi :**

    - Les panneaux STOP sont des **octogones** (8 cotes)
    - Les pizzas sont des **cercles**
    - Les fenetres sont souvent des **rectangles** ou des **carres**

### Points, droites et segments

| Element | Notation | Representation |
|---------|:---:|:---:|
| Point | A | . |
| Droite | (AB) ou (d) | <----------> |
| Segment | [AB] | .--------. |
| Demi-droite | [AB) | .--------> |

!!! info "A retenir"
    - Une **droite** est infinie des deux cotes (on peut toujours la prolonger)
    - Un **segment** a un debut et une fin (on peut le mesurer)
    - Une **demi-droite** a un debut mais pas de fin

??? abstract "Autre facon de comprendre : droite, segment, demi-droite"
    **Imagine une route :**

    - **Droite** = une route qui va a l'infini dans les deux sens (comme une autoroute sans fin)
    - **Segment** = un morceau de route entre deux villes (Paris-Lyon par exemple)
    - **Demi-droite** = une route qui part d'une ville et continue a l'infini (comme partir de chez toi et ne jamais s'arreter)

??? warning "Piege a eviter : les notations"
    - **[AB]** = segment (avec crochets = ferme des deux cotes)
    - **(AB)** = droite (avec parentheses = ouvert, infini)
    - **[AB)** = demi-droite (un crochet + une parenthese = ferme d'un cote, ouvert de l'autre)

    **Astuce : crochet = arret, parenthese = ca continue !**

## Droites perpendiculaires et paralleles

### Droites perpendiculaires

Deux droites sont **perpendiculaires** si elles forment un **angle droit** (90°).

```
        |
        |
        |
--------+--------
        |
        |
```

!!! note "Notation"
    On ecrit : **(d1) ⊥ (d2)**

    Le symbole **⊥** signifie "perpendiculaire a"

!!! tip "Comment tracer ?"
    Utilise l'**equerre** en placant l'angle droit sur la droite.

??? abstract "Autre facon de comprendre : perpendiculaire"
    **Pense a une croix (+) ou a un carrefour :**

    Quand deux routes se croisent a angle droit, elles sont perpendiculaires !

    Exemples : les coins d'une feuille, les bords d'une porte, le coin d'un livre...

### Droites paralleles

Deux droites sont **paralleles** si elles ne se croisent **jamais** (meme prolongees a l'infini).

```
------------------------

------------------------
```

!!! note "Notation"
    On ecrit : **(d1) // (d2)**

    Le symbole **//** signifie "parallele a"

??? abstract "Autre facon de comprendre : parallele"
    **Pense aux rails d'un train :**

    Les deux rails vont dans la meme direction et ne se touchent jamais. Ils sont paralleles !

    Autres exemples : les lignes d'un cahier, les bords opposes d'une regle...

!!! tip "Propriete importante"
    Si deux droites sont perpendiculaires a une meme troisieme droite, alors elles sont paralleles entre elles.

    ```
    (d1) -------|-------
                |
    (d3)        |
                |
    (d2) -------|-------
    ```

    Si (d1) ⊥ (d3) et (d2) ⊥ (d3), alors (d1) // (d2)

## Les angles

### Types d'angles

| Type | Mesure | Comment le reconnaitre |
|------|:---:|:---|
| Angle aigu | < 90° | Plus petit que le coin d'une feuille |
| Angle droit | = 90° | Comme le coin d'une feuille |
| Angle obtus | > 90° et < 180° | Plus grand que le coin d'une feuille |
| Angle plat | = 180° | Une ligne droite |

!!! example "Reconnaitre un angle"
    - Coin d'une feuille = angle **droit** (90°)
    - Pointe d'une fleche = angle **aigu** (< 90°)
    - Ouverture d'un livre = angle **obtus** (> 90°)

??? abstract "Autre facon de comprendre : les angles"
    **Utilise tes mains !**

    - Mets tes mains a plat, pouces contre pouces → angle **plat** (180°)
    - Leve une main → tu crees des angles de plus en plus petits
    - Quand tes mains sont perpendiculaires (comme un L) → angle **droit** (90°)

??? warning "Piege a eviter : aigu vs obtus"
    Beaucoup d'eleves confondent **aigu** et **obtus**.

    **Astuce :**

    - **Aigu** commence par A comme "A"minci → c'est le plus petit !
    - **Obtus** commence par O comme "O"uvert → c'est le plus grand !

### Mesurer avec le rapporteur

!!! note "Methode"
    1. Placer le **centre** du rapporteur sur le sommet de l'angle
    2. Aligner le **0°** sur un cote de l'angle
    3. Lire la graduation sur l'autre cote

??? warning "Piege a eviter : le rapporteur"
    Le rapporteur a **deux graduations** (une qui part de la gauche, une de la droite).

    **Astuce :** Verifie toujours que tu pars bien de **0°** !

    Si tu mesures un angle aigu, le resultat doit etre < 90°.
    Si tu mesures un angle obtus, le resultat doit etre > 90°.

## Les polygones

### Qu'est-ce qu'un polygone ?

Un polygone est une figure **fermee** formee de **segments**.

| Nombre de cotes | Nom |
|:---:|:---|
| 3 | Triangle |
| 4 | Quadrilatere |
| 5 | Pentagone |
| 6 | Hexagone |
| 8 | Octogone |

!!! tip "Astuce pour retenir"
    - **Tri** = 3 (comme tricycle)
    - **Quad** = 4 (comme quad, quadruple)
    - **Penta** = 5 (comme pentagone au foot US)
    - **Hexa** = 6 (comme les alveoles d'abeilles)
    - **Octo** = 8 (comme octopus = poulpe)

### Les triangles

#### Types de triangles (selon les cotes)

| Type | Propriete | Schema |
|------|-----------|:---:|
| **Scalene** | 3 cotes differents | △ quelconque |
| **Isocele** | 2 cotes egaux | △ avec 2 cotes pareils |
| **Equilateral** | 3 cotes egaux | △ parfait |

#### Types de triangles (selon les angles)

| Type | Propriete |
|------|-----------|
| **Rectangle** | 1 angle droit (90°) |
| **Acutangle** | 3 angles aigus (tous < 90°) |
| **Obtusangle** | 1 angle obtus (> 90°) |

!!! info "Propriete fondamentale"
    La somme des angles d'un triangle = **180°**

    Si tu connais 2 angles, tu peux trouver le 3eme !

??? abstract "Autre facon de comprendre : somme des angles"
    **Decoupe un triangle en papier :**

    1. Decoupe les 3 coins
    2. Aligne-les cote a cote
    3. Tu obtiens... un angle plat (180°) !

    Ca marche a chaque fois !

### Les quadrilateres

#### Le carre

!!! success "Proprietes du carre"
    - 4 cotes **egaux**
    - 4 angles **droits**
    - Diagonales egales et perpendiculaires
    - C'est le "champion" des quadrilateres !

#### Le rectangle

!!! success "Proprietes du rectangle"
    - Cotes opposes **egaux** et **paralleles**
    - 4 angles **droits**
    - Diagonales egales (mais pas perpendiculaires)

#### Le losange

!!! success "Proprietes du losange"
    - 4 cotes **egaux**
    - Cotes opposes paralleles
    - Diagonales **perpendiculaires** (mais pas egales)

??? abstract "Autre facon de comprendre : carre vs losange vs rectangle"
    **Le carre est special :**

    - Un carre est un **rectangle** (car 4 angles droits)
    - Un carre est aussi un **losange** (car 4 cotes egaux)
    - C'est le seul quadrilatere qui est les deux a la fois !

    **Le rectangle "penche"** → ca devient un losange (plus d'angles droits)
    **Le losange "redresse"** → ca devient un carre (angles droits)

#### Le parallelogramme

!!! success "Proprietes du parallelogramme"
    - Cotes opposes **egaux** et **paralleles**
    - Angles opposes egaux
    - C'est comme un rectangle "penche"

## Le cercle

### Vocabulaire du cercle

```
           . . .
       .           .
     .       r       .    O = centre
    .        |        .   r = rayon
    .   O----+----    .   d = diametre = 2r
    .        |        .
     .       r       .
       .           .
           . . .
```

| Element | Definition |
|---------|------------|
| **Centre** | Point O au milieu du cercle |
| **Rayon** | Segment du centre a un point du cercle |
| **Diametre** | Segment passant par le centre, d'un bord a l'autre |
| **Corde** | Segment reliant 2 points du cercle |

!!! note "Relation importante"
    **Diametre = 2 x Rayon**

    d = 2r

??? abstract "Autre facon de comprendre : rayon et diametre"
    **Pense a une pizza :**

    - Le **rayon** = du centre jusqu'au bord (un morceau de pizza triangulaire)
    - Le **diametre** = toute la largeur de la pizza (comme quand tu la coupes en deux)

    Le diametre, c'est comme 2 rayons mis bout a bout !

### Tracer un cercle

!!! tip "Methode avec le compas"
    1. Regler l'ecartement du compas = **rayon** voulu
    2. Placer la pointe seche sur le **centre**
    3. Tracer le cercle en tournant (sans bouger la pointe !)

??? warning "Piege a eviter : le compas"
    - Ne confonds pas **rayon** et **diametre** quand tu regles ton compas !
    - Si on te demande un cercle de diametre 6 cm, regle ton compas sur **3 cm** (le rayon)

## La symetrie axiale

### Qu'est-ce qu'une symetrie ?

Une figure a une **symetrie axiale** si on peut la plier le long d'un axe et que les deux moities se superposent exactement.

!!! example "Exemples de figures symetriques"
    - La lettre **A** : 1 axe vertical
    - Un carre : 4 axes de symetrie
    - Un rectangle : 2 axes de symetrie
    - Un cercle : infinite d'axes (tous les diametres !)

??? abstract "Autre facon de comprendre : la symetrie"
    **Pense a un miroir :**

    La symetrie, c'est comme se regarder dans un miroir. L'axe de symetrie, c'est le miroir !

    Si tu mets un miroir au milieu d'une figure symetrique, tu verras la figure complete.

    **Ou au pliage :**

    Si tu plies une feuille en deux et que tu decoupes une forme, en depliant tu obtiens une figure symetrique !

### Construire le symetrique d'un point

Pour construire le symetrique du point A par rapport a l'axe (d) :

!!! note "Methode"
    1. Tracer la perpendiculaire a (d) passant par A
    2. Mesurer la distance de A a (d)
    3. Reporter cette distance de l'autre cote de (d)
    4. Le point obtenu est A' (symetrique de A)

```
    A .
       \
        \  <- meme distance
    -----+------ (d) = axe de symetrie
        /
       /
    A'.
```

!!! info "Proprietes"
    - A et A' sont a la **meme distance** de l'axe
    - Le segment [AA'] est **perpendiculaire** a l'axe

## Exercices guides

### Exercice 1 : Vocabulaire

!!! question "Complete"
    a) Une droite est __________ des deux cotes.

    b) Un segment a un __________ et une __________.

??? success "Correction"
    a) Une droite est **infinie** des deux cotes.

    b) Un segment a un **debut** et une **fin**.

### Exercice 2 : Angles

!!! question "Classe ces angles"
    - 45° → angle __________
    - 90° → angle __________
    - 120° → angle __________

??? success "Correction"
    - 45° → angle **aigu**
    - 90° → angle **droit**
    - 120° → angle **obtus**

### Exercice 3 : Triangles

!!! question "Quel type de triangle ?"
    Un triangle a des cotes de 5 cm, 5 cm et 7 cm.

??? success "Correction"
    C'est un triangle **isocele** (2 cotes egaux : 5 cm et 5 cm)

### Exercice 4 : Quadrilateres

!!! question "Quel quadrilatere ?"
    Il a 4 cotes egaux mais pas d'angle droit.

??? success "Correction"
    C'est un **losange** (qui n'est pas un carre)

### Exercice 5 : Cercle

!!! question "Calcule"
    Un cercle a un rayon de 5 cm. Quel est son diametre ?

??? success "Correction"
    Diametre = 2 x rayon = 2 x 5 = **10 cm**

## Entrainement

### Serie 1 : Facile

!!! note "A faire sur ton cahier"
    1. Quel est le symbole pour "perpendiculaire" ?
    2. Combien de cotes a un hexagone ?
    3. Quelle est la somme des angles d'un triangle ?
    4. Un cercle de diametre 8 cm a un rayon de combien ?

??? success "Corrections"
    1. Le symbole est **⊥**
    2. Un hexagone a **6 cotes**
    3. La somme est **180°**
    4. Rayon = 8 / 2 = **4 cm**

### Serie 2 : Moyen

!!! note "A faire sur ton cahier"
    1. Un triangle a des angles de 60°, 60° et 60°. Quel est son type ?
    2. Cite 2 proprietes du carre.
    3. Quelle est la difference entre une droite et un segment ?
    4. Combien d'axes de symetrie a un rectangle ?

??? success "Corrections"
    1. C'est un triangle **equilateral** (3 angles egaux = 3 cotes egaux)
    2. 4 cotes egaux, 4 angles droits (ou : diagonales egales et perpendiculaires)
    3. Une droite est **infinie**, un segment a une **longueur definie**
    4. Un rectangle a **2** axes de symetrie

### Serie 3 : Difficile

!!! note "A faire sur ton cahier"
    1. Un triangle a deux angles de 50° et 70°. Combien mesure le 3eme angle ? Quel type de triangle est-ce ?
    2. Trace un carre ABCD de 4 cm de cote. Trace ses diagonales. Elles se coupent en un point O. Combien mesure [AO] ?
    3. Construis le symetrique du point M situe a 3 cm de l'axe (d).

??? success "Corrections"
    1. 3eme angle = 180 - 50 - 70 = **60°**. C'est un triangle **acutangle** (tous les angles < 90°)
    2. La diagonale d'un carre de 4 cm mesure environ 5,7 cm. Donc [AO] mesure environ **2,8 cm** (la moitie)
    3. Le point M' est a 3 cm de l'autre cote de l'axe (d), sur la perpendiculaire passant par M.

## Bonus : Defis

??? question "Defi 1 : Le triangle mystere"
    Je suis un triangle.
    J'ai un angle droit.
    Mes deux autres angles sont egaux.

    Combien mesurent mes deux autres angles ?

    ??? success "Reponse"
        180° - 90° = 90° a repartir entre 2 angles egaux

        Chaque angle = 90° / 2 = **45°**

        C'est un triangle rectangle isocele !

??? question "Defi 2 : Compte les triangles"
    Combien de triangles vois-tu dans cette figure ?

    ```
        /\
       /  \
      /----\
     /  /\  \
    /  /  \  \
    ----------
    ```

    ??? success "Reponse"
        Il y a **5 triangles** :
        - Le grand triangle
        - Le petit triangle du haut
        - Le triangle en bas a gauche
        - Le triangle en bas a droite
        - Le triangle du bas (forme par la base et les deux petits)

??? question "Defi 3 : La symetrie des lettres"
    Parmi ces lettres, lesquelles ont au moins un axe de symetrie ?

    A B C D E F G H

    ??? success "Reponse"
        - **A** : 1 axe vertical
        - **B** : 1 axe horizontal
        - **C** : 1 axe horizontal
        - **D** : 1 axe horizontal
        - **E** : 1 axe horizontal
        - F : aucun axe
        - G : aucun axe
        - **H** : 2 axes (vertical et horizontal)

        Lettres avec symetrie : **A, B, C, D, E, H**
